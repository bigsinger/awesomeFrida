# 12.2 视频App解密：M3U8替换

> 核心要点：视频 App 通常通过 M3U8 播放列表中的 `start=` 和 `end=` 参数控制视频的试看时长和分段。通过 Frida Hook `java.net.URL` 构造函数，可以动态替换这些参数，实现"无限制"播放。本章完整分析 `replaceM3U8url.js` 脚本的实现原理。

## 1. M3U8 视频播放原理

### 1.1 M3U8 格式简介

M3U8 是 HTTP Live Streaming（HLS）协议使用的播放列表文件格式，由苹果公司提出。视频内容被切分为多个小的 TS（MPEG-2 Transport Stream）分片，客户端根据 M3U8 文件中的 URL 列表按序下载播放。

```
典型 M3U8 文件内容：
#EXTM3U
#EXT-X-VERSION:3
#EXT-X-TARGETDURATION:10
#EXTINF:10.000,
segment_00001.ts?start=0&end=100000
#EXTINF:10.000,
segment_00002.ts?start=100000&end=200000
...
```

### 1.2 视频试看限制机制

视频 App 通过两种方式实现试看/会员限制：

```
方式一：URL 参数控制
    播放列表 URL 包含 start/end/trial 参数
    免费用户 → start=0&end=60000 （仅试看 60 秒）
    会员用户 → start=0&end=99999999（完整播放）

方式二：Token 鉴权
    每个分片 URL 携带临时 Token
    免费用户的 Token 只有部分分片的权限
```

## 2. replaceM3U8url.js 完整分析

> **引用源文件**：`awesomeFrida/replaceM3U8url.js`（完整29行代码）

### 2.1 核心思路

通过 Hook `java.net.URL` 的字符串构造函数，在所有 URL 创建时检测是否包含 `start=` 和 `end=` 参数。如果命中，则替换为自定义值（如 `start=0&end=99999`），从而绕过试看限制。

### 2.2 完整脚本逐行分析

```javascript
// 引用：awesomeFrida/replaceM3U8url.js 第1-12行（hookURL 函数）
function hookURL() {
    var URL = Java.use('java.net.URL');
    URL.$init.overload('java.lang.String').implementation = function (url) {
        // 检测 URL 是否包含 start= 和 end= 参数
        if (url.indexOf('start=') > 0 && url.indexOf('end=') > 0) {
            //console.log('URL：' + url);
            var url2 = replaceUrlArgs(url, "start", 0);
            url2 = replaceUrlArgs(url2, "end", 99999);
            console.log('URL：' + url2);
            this.$init(url2);  // 使用替换后的 URL 初始化
        } else {
            this.$init(url);   // 非目标 URL 保持原样
        }
    }
}
```

**关键点解析：**

| 代码要素 | 说明 |
|:---------|:-----|
| `Java.use('java.net.URL')` | 获取 Java 中的 URL 类 |
| `$init.overload('java.lang.String')` | Hook 单字符串参数的构造函数 |
| `url.indexOf('start=')` | 检测 URL 中是否包含目标参数 |
| `this.$init(url2)` | 使用新 URL 字符串调用原始构造函数 |

### 2.3 URL 参数替换函数

```javascript
// 引用：awesomeFrida/replaceM3U8url.js 第14-22行（replaceUrlArgs 函数）
// 方案一：使用正则表达式直接替换
function replaceUrlArgs(url, name, value) {
    const re = new RegExp(name + '=[^&]*', 'gi');
    return url.replace(re, name + '=' + value);
}

// 方案二：使用正则后向断言（零宽断言）
function replaceUrlArgs2(url, name, value) {
    const re = new RegExp(`(?<=${name}=)[^&]*`, 'g');
    return url.replace(re, value);
}
```

**两种方案的对比：**

| 方案 | 说明 | 示例 |
|:----|:-----|:-----|
| `replaceUrlArgs` | 整体替换 `name=value` | `start=0` → `start=99999` |
| `replaceUrlArgs2` | 仅替换 value 部分 | `start=0` → `start=99999` |

`replaceUrlArgs2` 使用了 ES2018 的正则后向断言（`(?<=...)`），更精准但兼容性略差。

### 2.4 主流程

```javascript
// 引用：awesomeFrida/replaceM3U8url.js 第24-29行
function hook() {
    Java.perform(function () {
        hookURL();
    });
}

setImmediate(hook());
```

**为什么使用 setImmediate？**

`setImmediate` 确保回调在当前事件循环的"检查阶段"执行，比 `setTimeout(fn, 0)` 效率更高。在 Frida 脚本中，它保证了 Java 环境初始化完成后才执行 Hook。

## 3. 扩展：通用 URL 替换方案

### 3.1 多参数批量替换

```javascript
// 扩展：支持多个参数同时替换
function hookURLAdvanced() {
    var URL = Java.use('java.net.URL');
    URL.$init.overload('java.lang.String').implementation = function (url) {
        var pairs = [
            { name: 'start', value: 0 },
            { name: 'end', value: 99999 },
            { name: 'trial', value: 0 },
            { name: 'limit', value: 0 },
            { name: 'expires', value: '9999999999' }
        ];
        var modified = false;
        pairs.forEach(function(pair) {
            if (url.indexOf(pair.name + '=') > 0) {
                url = replaceUrlArgs(url, pair.name, pair.value);
                modified = true;
            }
        });
        if (modified) {
            console.log('Modified URL: ' + url);
            // printStack(); // 可选：打印调用堆栈
        }
        this.$init(url);
    }
}
```

## 4. 进阶：Token 鉴权的 M3U8 替换

部分视频 App 使用 Token 鉴权，需要同时替换 Token 或在 Token 生成阶段进行 Hook：

```javascript
// 进阶方案：替换 M3U8 请求中的鉴权 Token
function hookToken() {
    Java.perform(function () {
        // 方式一：Hook HashMap put，拦截所有请求参数
        var HashMap = Java.use("java.util.HashMap");
        HashMap.put.implementation = function (key, value) {
            if (key.indexOf("token") >= 0 || key.indexOf("sign") >= 0) {
                console.log("Token/Sign detected: " + key + " = " + value);
            }
            return this.put(key, value);
        };

        // 方式二：Hook URL 并添加 Token 参数
        var URL = Java.use('java.net.URL');
        URL.$init.overload('java.lang.String').implementation = function (url) {
            if (url.indexOf('.ts') > 0 || url.indexOf('.m3u8') > 0) {
                // 自动追加高权限 Token
                if (url.indexOf('token=') < 0) {
                    url = url + '&token=HIGH_PRIVILEGE_TOKEN';
                }
                console.log('Token added: ' + url);
            }
            this.$init(url);
        };
    });
}
```

# 配合 URL 监控脚本

### 5.3 验证视频播放

被替换参数后，原本只能试看前几秒的视频应能完整播放。如果仍受限，说明 App 可能使用了 Token 鉴权或服务端校验。

## 6. 常见问题与排查

| 问题 | 可能原因 | 解决方案 |
|:----|:---------|:---------|
| **替换未生效** | URL 未通过 `java.net.URL` 创建 | App 可能使用原生代码直接拼接 URL |
| **播放白屏** | 参数替换导致服务器拒绝 | 调整 `end` 值，尝试服务器返回的实际值 |
| **参数名称不同** | App 使用自定义参数名 | 通过 URL 监控确认实际参数名 |
| **部分替换成功** | 多线程并发创建 URL | Hook 所有 URL 重载构造函数 |
| **播放卡顿** | 替换后请求的数据量过大 | 适当调低 `end` 值 |

## 小结

- **M3U8 替换**的核心思路是 Hook `java.net.URL` 构造函数，拦截并修改包含 `start=` / `end=` 参数的视频 URL
- **`replaceM3U8url.js`**（29行）实现了一个简洁高效的参数替换方案，仅需 Hook 一个构造函数即可奏效
- **正则表达式替换**提供了两种实现：正向替换和后向断言替换，可根据浏览器兼容性选择
- 此方案不仅适用于 M3U8 视频流，也可推广到任何使用 URL 参数控制权限的场景
- 对于 Token 鉴权的高级场景，需要结合 HashMap Hook 或 API Hook 获取高权限 Token

> **参考源文件**：`awesomeFrida/replaceM3U8url.js`（完整29行代码）实现了通过 Hook java.net.URL 构造函数替换视频流 URL 参数的完整方案。
