# 12.5 混淆App分析与脱壳

> 核心要点：加固混淆的 App 通常对 DEX、SO、资源文件进行了多重保护。本章综合使用 360 加固分析、Dump 技巧（DEX/SO/Lua 脚本），结合 `360getString.js` 和 `MT.js` 的完整思路，提供一套完整的混淆 App 逆向方案。

## 1. 加固方案概述

### 1.1 常见加固方案

| 加固厂商 | 保护特点 | 对抗难度 |
|:---------|:---------|:---------|
| 360 加固 | 字符串加密、DEX VMP、SO 加壳 | 中等 |
| 腾讯加固 | DEX 整体加密、SO 加壳、反调试 | 中等偏高 |
| 梆梆加固 | 多 Dex 加密、Java 2 C 混淆 | 高 |
| 娜迦加固 | VMP、反调试、资源加密 | 高 |
| 网易易盾 | DEX 动态解密、SO 保护、混淆 | 高 |

### 1.2 混淆 App 的通用分析流程

```
目标 APK
    ↓
静态分析
    ├── 反编译（jadx / GDA）
    ├── 查看 AndroidManifest（Application 类名）
    └── 识别加固类型（查壳工具）
    ↓
动态脱壳
    ├── DEX Dump（FRIDA-DEXDump / frida_dump）
    ├── SO Dump（dump-so.js）
    ├── Lua 脚本提取（MT.js 思路）
    └── 字符串解密（360getString.js）
    ↓
脱壳后分析
    ├── jadx 反编译 DEX
    ├── IDA Pro 分析 SO
    └── 跟踪关键逻辑
```

## 2. 360 加固分析与字符串解密

### 2.1 360 加固原理

360 加固的核心架构：

```
360 加固壳
    ↓
StubApp（壳入口）
    ├── getString / getString2 → 字符串解密
    ├── 多 Dex 分发
    └── SO 加载与校验
    ↓
原始 DEX（运行时解密到内存）
    ↓
原始 SO（解密后加载）
```

### 2.2 360getString.js 完整分析

> **引用源文件**：`awesomeFrida/360getString.js`（完整17行代码）

```javascript
// 引用：awesomeFrida/360getString.js 完整代码
function decode360String(s){
    if (!s) {
        console.log('请输入360加固的密文字符串!');
        return;
    }

    Java.perform(function(){
        var Class = Java.use('com.stub.StubApp');
        var result = Class.getString2(s);
        console.log('解密结果: ' + result);
    });
}
```

**核心思路：**

360 加固将所有字符串加密存储在壳中，运行时通过 `StubApp.getString/getString2` 解密。Frida 可以直接调用这个解密方法，将密文字符串还原为明文。

**使用方式：**

```javascript
// 在控制台中手动调用
decode360String("加密字符串内容");

// 或在脚本中批量解密
function batchDecrypt(encryptedStrings) {
    Java.perform(function(){
        var StubApp = Java.use('com.stub.StubApp');
        encryptedStrings.forEach(function(s) {
            try {
                var plain = StubApp.getString2(s);
                console.log("密文: " + s + " → 明文: " + plain);
            } catch(e) {
                console.log("解密失败: " + s);
            }
        });
    });
}

// 自动 Hook：捕获所有 StubApp.getString2 调用
function hookStubAppDecrypt() {
    Java.perform(function(){
        var StubApp = Java.use('com.stub.StubApp');
        
        StubApp.getString2.overload('java.lang.String').implementation = function (s) {
            var result = this.getString2(s);
            console.log("[360 Decrypt] " + s + " → " + result);
            return result;
        };
        
        StubApp.getString.overload('java.lang.String').implementation = function (s) {
            var result = this.getString(s);
            console.log("[360 Decrypt] " + s + " → " + result);
            return result;
        };
    });
}
```

### 2.3 自动化 Hook 加密字符串

```javascript
// 完整方案：Hook HashMap.put 自动捕获传递到 StubApp 的字符串
function autoCapture360Strings() {
    Java.perform(function(){
        // Hook HashMap 捕获所有 put 操作
        var HashMap = Java.use("java.util.HashMap");
        HashMap.put.implementation = function (key, value) {
            // 检测如果 value 是加密字符串格式
            if (key != null && value != null) {
                var strValue = value.toString();
                if (strValue.length > 10 && strValue.contains("==") ||
                    strValue.contains("加密") || strValue.contains("key")) {
                    console.log("[HashMap] " + key + " = " + strValue);
                }
            }
            return this.put(key, value);
        };

        // Hook 360 加固的字符串解密
        var StubApp = Java.use('com.stub.StubApp');
        StubApp.getString2.implementation = function (s) {
            var result = this.getString2(s);
            // 将解密结果存储到文件
            var File = Java.use("java.io.File");
            var FileOutputStream = Java.use("java.io.FileOutputStream");
            var file = File.$new("/data/data/com.example.app/cache/decrypt_log.txt");
            var fos = FileOutputStream.$new(file, true);
            var str = s + " → " + result + "\n";
            fos.write(str.getBytes());
            fos.close();
            return result;
        };
    });
}
```

### 3.2 手动 Dump DEX 脚本

```javascript
// 手动 Dump DEX：Hook ClassLoader 的 defineClass
function manualDumpDex() {
    Java.perform(function () {
        var DexFile = Java.use("dalvik.system.DexFile");
        var BaseDexClassLoader = Java.use("dalvik.system.BaseDexClassLoader");

        // Hook loadClass 捕获动态加载的类
        BaseDexClassLoader.loadClass.implementation = function (className) {
            var result = this.loadClass(className);
            if (className.indexOf("关键类名前缀") >= 0) {
                console.log("Dynamic class loaded: " + className);
            }
            return result;
        };

        // 方案B：枚举已加载的 DEX
        Java.enumerateClassLoaders({
            onMatch: function (loader) {
                console.log("ClassLoader: " + loader);
            },
            onComplete: function () { }
        });
    });
}

// Dump 内存中所有 DEX 文件
function dumpAllDex() {
    Java.perform(function () {
        // 获取所有已加载的 DEX
        Java.enumerateLoadedClasses({
            onMatch: function (className) {
                // 可以通过反射获取类的 DexFile 对象
                // 但更常用的方案是内存扫描 DEX 魔头
            },
            onComplete: function () { }
        });

        // 内存扫描 DEX 魔头 "dex\n035" 或 "dex\n038"
        Process.enumerateModules({
            onMatch: function (module) {
                // 在每个模块的内存中搜索 DEX 魔头
                var pattern = "64 65 78 0A 30 33"; // "dex\n03" hex
                var matches = Memory.scanSync(module.base, module.size, pattern);
                matches.forEach(function (match) {
                    console.log("Found DEX at: " + match.address +
                                " in module: " + module.name);
                });
            },
            onComplete: function () { }
        });
    });
}
```

### 3.3 Dump 加固后的 SO 文件

> **引用源文件**：`awesomeFrida/dump-so.js`

```bash
# 使用 dump-so.js Dump 已加载的 SO
frida -U -f com.example.app -l dump-so.js --no-pause
```

```javascript
// 核心思路：在 dlopen 后，内存中复制 SO
function dumpSo(moduleName) {
    var module = Process.getModuleByName(moduleName);
    console.log("Module: " + moduleName);
    console.log("Base: " + module.base);
    console.log("Size: " + module.size);

    // 从内存中复制 SO 数据
    var soBytes = Memory.readByteArray(module.base, module.size);

    // ELF 魔头验证
    var magic = Memory.readCString(module.base);
    if (magic === "\x7fELF") {
        console.log("ELF magic verified");
    }

    // 保存到文件
    var filename = "/data/local/tmp/" + moduleName + ".dump";
    Java.perform(function () {
        var file = Java.use("java.io.FileOutputStream").$new(filename);
        file.write(soBytes);
        file.close();
        console.log("Dumped to: " + filename);
    });
}
```

## 4. Lua 脚本提取（MT.js）

> **引用源文件**：`awesomeFrida/MT.js`（完整262行代码）

### 4.1 应用场景

MT 管理器（及其他使用 Cocos2d-x/Cocos2d-js 引擎的游戏/App）将游戏逻辑以 Lua 脚本形式打包在 APK 中。这些脚本可能被 XXTEA 加密或自定义加密，需要在运行时提取。

### 4.2 核心技术：dlopen 延迟 Hook

```javascript
// 引用：awesomeFrida/MT.js 第33-51行
var android_dlopen_ext = Module.findExportByName(null, "android_dlopen_ext");
if (android_dlopen_ext != null) {
    Interceptor.attach(android_dlopen_ext, {
        onEnter: function (args) {
            var soName = args[0].readCString();
            if (soName.indexOf("libgame.so") != -1) {
                console.log("android_dlopen_ext: " + soName);
                this.hook = true;
            }
        },
        onLeave: function (retval) {
            if (this.hook) {
                dlopentodo();  // 延迟执行 Hook
                console.log("hook ok");
            }
        }
    });
}
```

### 4.3 通过 getFileData 提取 Lua

```javascript
// 引用：awesomeFrida/MT.js 第93-120行
Interceptor.attach(
    Module.findExportByName("libgame.so",
        "_ZN7cocos2d11CCFileUtils11getFileDataEPKcS2_Pmb"),
    {
        onEnter: function (args) {
            var name = Memory.readCString(args[1]);
            this.fileDescriptor = name;
            this.sizePtr = ptr(args[3]);
            if (name.indexOf("target_script.lua") != -1) {
                console.log("getFileData onEnter, name: " + name);
            }
        },
        onLeave: function (retval) {
            if (this.fileDescriptor.indexOf("target_script.lua") != -1) {
                var name = this.fileDescriptor;
                var size = Memory.readInt(this.sizePtr);
                console.log("getFileData onLeave, name: " + name +
                            " size: " + size);
                
                // 保存为文件
                if (!name.endsWith(".lua")) { name = name + ".lua"; }
                var filename = "/data/user/0/" + PACKAGENAME + "/"
                    + SAVEDIR + "/" + name.split("/").join(".");
                save2File(filename, Memory.readByteArray(retval, size));
            }
        }
    }
);
```

## 5. 综合脱壳实战脚本

```javascript
// 综合脱壳脚本：同时 Dump DEX、SO、Lua
function comprehensiveDump() {
    // ===== 1. DEX Dump =====
    Java.perform(function () {
        // 搜索 DEX 魔头
        var pattern = "64 65 78 0A 30 33"; // "dex\n03"
        Process.enumerateModules({
            onMatch: function (module) {
                var matches = Memory.scanSync(module.base, module.size, pattern);
                matches.forEach(function (match) {
                    console.log("[DEX] Found at: " + match.address +
                                " in: " + module.name +
                                " size: " + module.size);
                });
            },
            onComplete: function () { }
        });

        // 输出所有 ClassLoader
        Java.enumerateClassLoaders({
            onMatch: function (loader) {
                console.log("[ClassLoader] " + loader.toString());
            },
            onComplete: function () { }
        });
    });

    // ===== 2. SO Dump =====
    var targetSos = ["libgame.so", "libcocos2djs.so", "libSecShell.so"];
    targetSos.forEach(function (soName) {
        try {
            dumpSo(soName);
        } catch (e) {
            console.log("[SO] " + soName + " not loaded: " + e);
        }
    });

    // ===== 3. Lua Dump（等待 dlopen 后执行）=====
    var PACKAGENAME = "com.example.app";
    var SAVEDIR = "dump_cache";

    var android_dlopen_ext = Module.findExportByName(null, "android_dlopen_ext");
    if (android_dlopen_ext != null) {
        Interceptor.attach(android_dlopen_ext, {
            onEnter: function (args) {
                var soName = args[0].readCString();
                if (soName.indexOf("libgame.so") != -1) {
                    this.hook = true;
                }
            },
            onLeave: function (retval) {
                if (this.hook) {
                    hookLuaFunctions();
                }
            }
        });
    }

    function hookLuaFunctions() {
        // 同 MT.js 的 getFileData + luaL_loadbuffer Hook
        console.log("[Lua] Hook started");
    }
}

function dumpSo(moduleName) {
    try {
        var module = Process.getModuleByName(moduleName);
        var soBytes = Memory.readByteArray(module.base, module.size);
        var filename = "/data/local/tmp/" + moduleName + ".dump";
        Java.perform(function () {
            var file = Java.use("java.io.FileOutputStream").$new(filename);
            file.write(soBytes);
            file.close();
            console.log("[SO] Dumped: " + moduleName + " → " + filename);
        });
    } catch (e) {
        console.log("[SO] Failed: " + moduleName + " - " + e);
    }
}

setTimeout(comprehensiveDump, 5000);
```

## 6. 常见问题与排查

| 问题 | 可能原因 | 解决方案 |
|:----|:---------|:---------|
| **找不到 StubApp 类** | 非360加固或类名混淆 | 搜 `getString` / `getString2` 方法签名 |
| **DEX Dump 不完整** | 加固使用 VMP 将部分逻辑转为 Native | 配合 Stalker 追踪 Native 调用 |
| **SO 文件被加密** | SO 本身被二次加密 | 在 `dlopen` 的 onLeave 后立即 Dump |
| **Lua 数据为空** | 使用自定义文件加载接口 | Hook `fopen`、`read` 等 C 函数 |
| **无法 Attach** | 加固的反调试机制 | 使用 spawn 模式或 Frida Gadget |

## 7. 进阶：VMP 与 OLLVM 混淆对抗

对于经过 VMP 或 OLLVM 混淆的 App，静态分析基本失效，需要动态分析：

```javascript
// 使用 Stalker 追踪混淆后的 Native 代码
function stalkerTraceModule(moduleName) {
    var module = Process.getModuleByName(moduleName);
    
    Stalker.follow(Process.getCurrentThreadId(), {
        events: {
            call: true,
            ret: true,
            exec: true
        },
        transform: function (iterator) {
            var instruction = iterator.next();
            var count = 0;
            while (instruction && count < 1000) {
                // 只追踪目标模块内的指令
                if (instruction.address >= module.base &&
                    instruction.address < module.base.add(module.size)) {
                    console.log(instruction.address + ": " +
                                instruction.mnemonic + " " +
                                instruction.opStr);
                }
                iterator.keep();
                instruction = iterator.next();
                count++;
            }
        }
    });
}
```

## 小结

- **360 加固字符串解密**：直接调用 `StubApp.getString2()` 方法，配合 `360getString.js`（17行）实现一键解密
- **DEX Dump**：使用 FRIDA-DEXDump 或手动内存扫描 DEX 魔头 `"dex\n035"`
- **SO Dump**：在 `dlopen` 的 onLeave 中立即从内存复制 SO 数据
- **Lua 脚本提取**：使用 `MT.js`（262行）的思路，通过 `getFileData` + `luaL_loadbuffer` 双 Hook 实现
- **核心模式**：`dlopen` 延迟 Hook → 目标 SO 加载后立即注入 → 数据提取与保存

> **参考源文件**：`awesomeFrida/360getString.js`（17行）实现360加固字符串解密；`awesomeFrida/MT.js`（262行）实现 Cocos2d 游戏 Lua 脚本提取；`awesomeFrida/dump-so.js` 实现 SO 文件内存 Dump。
