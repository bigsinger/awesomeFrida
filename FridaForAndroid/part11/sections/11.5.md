# 11.5 WebView 网络请求监控

> 核心要点：Hook `android.webkit.WebView.loadUrl` 可以拦截 App 中所有通过 WebView 发起的 URL 加载请求，适用于分析 Hybrid App、网页游戏、Web 支付等场景的 URL 跳转行为。

## 1. WebView.loadUrl Hook 基础

### 1.1 极简 Hook 脚本

> **引用源文件**：`awesomeFrida/webview-load-url.js`（完整3行代码）

```javascript
// 引用：awesomeFrida/webview-load-url.js（完整3行代码）
Java.use("android.webkit.WebView").loadUrl.overload("java.lang.String").implementation = function (s) {
    send(s.toString());
    this.loadUrl.overload("java.lang.String").call(this, s);
};
```

这 3 行代码完成了完整的 WebView URL 拦截功能：

1. `Java.use("android.webkit.WebView")` — 定位 WebView 类
2. `.loadUrl.overload("java.lang.String")` — 锁定参数为 String 的重载版本
3. `.implementation = function(s)` — 替换实现
4. `send(s.toString())` — 通过 Frida 的 send 机制将 URL 发送到客户端
5. `this.loadUrl(...)` — 调用原始方法，不阻塞正常功能

### 1.2 运行方式

```bash
# 使用 spawn 模式（从应用启动就开始监控）
frida -U -l webview-load-url.js -f com.example.app --no-pause

# 或 attach 到已运行的进程
frida -U -l webview-load-url.js com.example.app

# 使用 Python 客户端接收 URL 数据
```

**Python 客户端：**

```python
import frida
import sys

def on_message(message, data):
    if message['type'] == 'send':
        url = message['payload']
        print(f"[WebView] Loading URL: {url}")

device = frida.get_usb_device()
session = device.attach("com.example.app")

with open("webview-load-url.js") as f:
    script = session.create_script(f.read())

script.on("message", on_message)
script.load()
sys.stdin.read()
```

## 2. WebView 加载 URL 的多种方式

`WebView.loadUrl` 有多种重载形式，除了最常用的 `loadUrl(String)`，还有：

| 方法签名 | 说明 | 
|:---|:---|
| `loadUrl(String url)` | 加载指定 URL |
| `loadUrl(String url, Map<String, String> additionalHttpHeaders)` | 加载 URL 并添加自定义 HTTP 头 |
| `loadData(String data, String mimeType, String encoding)` | 加载 HTML 数据（非 URL） |
| `loadDataWithBaseURL(String baseUrl, String data, String mimeType, String encoding, String historyUrl)` | 带基准 URL 加载 HTML |
| `postUrl(String url, byte[] postData)` | POST 方式加载 URL |
| `evaluateJavascript(String script, ValueCallback callback)` | 执行 JavaScript（非 URL 加载但值得监控） |

完整 Hook 方案：

```javascript
// 完整 WebView 请求监控
Java.perform(function() {
    var WebView = Java.use("android.webkit.WebView");

    // 1. loadUrl(String)
    WebView.loadUrl.overload("java.lang.String").implementation = function(s) {
        console.log("[WebView] loadUrl: " + s);
        return this.loadUrl(s);
    };

    // 2. loadUrl(String, Map)
    WebView.loadUrl.overload("java.lang.String", "java.util.Map").implementation = function(url, headers) {
        console.log("[WebView] loadUrl with headers: " + url);
        console.log("[WebView] headers: " + headers.toString());
        return this.loadUrl(url, headers);
    };

    // 3. loadData
    WebView.loadData.overload("java.lang.String", "java.lang.String", "java.lang.String").implementation = function(data, mime, encoding) {
        console.log("[WebView] loadData (mime: " + mime + ", encoding: " + encoding + ")");
        console.log("[WebView] data length: " + data.length());
        // 注意：data 可能很大，谨慎输出
        return this.loadData(data, mime, encoding);
    };

    // 4. loadDataWithBaseURL
    WebView.loadDataWithBaseURL.overload(
        "java.lang.String", "java.lang.String",
        "java.lang.String", "java.lang.String", "java.lang.String"
    ).implementation = function(baseUrl, data, mime, encoding, historyUrl) {
        console.log("[WebView] loadDataWithBaseURL: base=" + baseUrl);
        console.log("[WebView] data length: " + data.length());
        return this.loadDataWithBaseURL(baseUrl, data, mime, encoding, historyUrl);
    };

    // 5. postUrl
    WebView.postUrl.overload("java.lang.String", "[B").implementation = function(url, postData) {
        console.log("[WebView] postUrl: " + url);
        console.log("[WebView] postData length: " + postData.length);
        return this.postUrl(url, postData);
    };

    // 6. evaluateJavascript
    WebView.evaluateJavascript.overload("java.lang.String", "android.webkit.ValueCallback").implementation = function(script, callback) {
        console.log("[WebView] evaluateJavascript: " + script);
        return this.evaluateJavascript(script, callback);
    };
});
```

## 3. 进阶：WebViewClient 回调监控

除了 Hook `loadUrl`，监控 `WebViewClient` 的回调方法可以获得更多信息：

```javascript
// 监控 WebViewClient 的回调
Java.perform(function() {
    // Hook shouldOverrideUrlLoading（控制 URL 是否由 WebView 处理）
    var WebViewClient = Java.use("android.webkit.WebViewClient");

    WebViewClient.shouldOverrideUrlLoading.overload(
        "android.webkit.WebView", "android.webkit.WebResourceRequest"
    ).implementation = function(view, request) {
        var url = request.getUrl().toString();
        console.log("[WebViewClient] shouldOverrideUrlLoading: " + url);
        console.log("[WebViewClient] method: " + request.getMethod());
        console.log("[WebViewClient] isRedirect: " + request.isRedirect());
        // 返回 false 表示由 WebView 继续加载
        return false;
    };

    // 监控页面加载状态
    WebViewClient.onPageStarted.overload(
        "android.webkit.WebView", "java.lang.String", "android.graphics.Bitmap"
    ).implementation = function(view, url, favicon) {
        console.log("[WebViewClient] onPageStarted: " + url);
        this.onPageStarted(view, url, favicon);
    };

    WebViewClient.onPageFinished.overload(
        "android.webkit.WebView", "java.lang.String"
    ).implementation = function(view, url) {
        console.log("[WebViewClient] onPageFinished: " + url);
        this.onPageFinished(view, url);
    };

    // 监控加载错误
    WebViewClient.onReceivedError.overload(
        "android.webkit.WebView", "int", "java.lang.String", "java.lang.String"
    ).implementation = function(view, errorCode, description, failingUrl) {
        console.log("[WebViewClient] onReceivedError: " + failingUrl +
                    " [" + errorCode + "] " + description);
        this.onReceivedError(view, errorCode, description, failingUrl);
    };

    // 监控 SSL 错误
    WebViewClient.onReceivedSslError.overload(
        "android.webkit.WebView", "android.webkit.SslErrorHandler", "android.net.http.SslError"
    ).implementation = function(view, handler, error) {
        console.log("[WebViewClient] onReceivedSslError: " + error.getUrl());
        // 可在此处调用 handler.proceed() 绕过 SSL 错误
        this.onReceivedSslError(view, handler, error);
    };
});
```

## 4. WebChromeClient 监控

部分 WebView 操作通过 WebChromeClient 回调：

```javascript
Java.perform(function() {
    var WebChromeClient = Java.use("android.webkit.WebChromeClient");

    // 监控 JavaScript 弹窗
    WebChromeClient.onJsAlert.overload(
        "android.webkit.WebView", "java.lang.String",
        "java.lang.String", "android.webkit.JsResult"
    ).implementation = function(view, url, message, result) {
        console.log("[WebChromeClient] onJsAlert: " + url + " -> " + message);
        return this.onJsAlert(view, url, message, result);
    };

    // 监控标题变化
    WebChromeClient.onReceivedTitle.overload(
        "android.webkit.WebView", "java.lang.String"
    ).implementation = function(view, title) {
        console.log("[WebChromeClient] onReceivedTitle: " + title);
        this.onReceivedTitle(view, title);
    };
});
```

## 5. 实战场景

### 5.1 支付流程分析

```python
# Python 客户端：分析支付 URL
def on_message(message, data):
    if message['type'] == 'send':
        url = message['payload']
        if any(keyword in url for keyword in ['pay', 'alipay', 'wxpay', 'unionpay']):
            print(f"[PAYMENT] {url}")
            # 保存到文件
            with open('payment_urls.txt', 'a') as f:
                f.write(url + '\n')
```

### 5.2 Hybrid App JS Bridge 分析

```javascript
// 监控 JS Bridge 调用（常见的 addJavascriptInterface）
Java.perform(function() {
    WebView.addJavascriptInterface.overload(
        "java.lang.Object", "java.lang.String"
    ).implementation = function(obj, name) {
        console.log("[WebView] addJavascriptInterface: " + name +
                    " -> " + obj.getClass().getName());
        return this.addJavascriptInterface(obj, name);
    };
});
```

### 5.3 URL 修改

```javascript
// 在 loadUrl 中修改 URL
Java.use("android.webkit.WebView").loadUrl.overload("java.lang.String").implementation = function(s) {
    // 重定向特定的 URL
    if (s.contains("advertisement")) {
        console.log("[Blocked] Advertisement URL: " + s);
        return;  // 阻止广告加载
    }
    // 修改请求
    var modifiedUrl = s.replace("http://", "https://");
    console.log("[Modified] " + s + " -> " + modifiedUrl);
    return this.loadUrl(modifiedUrl);
};
```

## 6. 注意事项

| 注意事项 | 说明 |
|:--------|:----|
| **性能影响** | 如果 WebView 频繁加载 URL（如广告轮播），大量 send 调用可能影响性能，建议过滤 |
| **参数编码** | URL 可能包含中文或特殊字符，注意编码问题 |
| **WebView 复用** | 同一个 WebView 可能加载多个 URL，通过 Hook 可追踪跳转序列 |
| **多 WebView** | App 可能同时存在多个 WebView 实例，Hook 会监控所有实例 |
| **APT 检测** | 某些安全 App 会检测 WebView 的异常行为，注意规避 |
