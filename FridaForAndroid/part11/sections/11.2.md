# 11.2 自定义类注册

> 核心要点：Frida 的 `Java.registerClass` 允许在运行时动态创建 Java 类并注入到目标进程。这种技术在回调注入、主动调用、以及在异步线程中执行代码等场景下非常实用。

## 1. 为什么需要自定义类注册

标准的 Frida Java Hook 遵循 "注入脚本 → 拦截方法 → 修改逻辑" 的流程。但在某些场景下，我们需要在目标进程中**创建全新的 Java 类**：

| 场景 | 说明 | 不使用自定义类的局限 |
|:---:|:---|:---|
| **Runnable 回调** | 需要在子线程中执行代码 | 无法直接创建 Runnable 实例 |
| **接口实现** | 需要实现某个 Java 接口 | 无法动态实现接口方法 |
| **回调注入** | 需要将自定义对象注册为系统回调 | 无法创建回调对象 |
| **主动调用辅助** | 需要构造复杂参数后调用目标方法 | Java 对象无法在 JS 中直接构造 |

## 2. Java.registerClass API 详解

```javascript
var MyClass = Java.registerClass({
    name: "com.example.MyNewClass",     // 类的全限定名
    superClass: /* 父类 */,              // 可选，继承的父类
    implements: [/* 接口数组 */],         // 可选，实现的接口
    fields: {                            // 可选，定义的字段
        fieldName: "java.lang.String",   // 字段名: 字段类型
    },
    methods: {                           // 定义的方法
        $init: [{                        // 构造方法（可重载）
            returnType: "void",
            argumentTypes: ["int", "java.lang.String"],
            implementation: function(intArg, strArg) {
                // 构造函数体
            }
        }],
        methodName: [{                   // 普通方法（可重载）
            returnType: "int",
            argumentTypes: ["int"],
            implementation: function(arg) {
                // 方法体
                return 0;
            }
        }],
        // 实现接口方法
        interfaceMethod: function() {
            // 方法体
        }
    }
});
```

### 参数详解

| 参数 | 是否必须 | 说明 |
|:---:|:--------:|:---|
| `name` | 是 | 类的完整包名+类名，必须与目标应用包名不同以避免冲突 |
| `superClass` | 否 | 父类，必须是已加载的 Java 类的 Frida 封装（通过 Java.use 获取） |
| `implements` | 否 | 接口数组，元素是通过 Java.use 获取的接口 |
| `fields` | 否 | 字段定义，`{"字段名": "Java类型字符串"}` |
| `methods` | 是 | 方法定义，支持构造方法 `$init` 和自定义方法 |

## 3. 实战：创建 Runnable 实现类

> **参考思路**：`Chap03/hello_world.js` 展示了基础的类注册与方法调用模式。

### 3.1 基础 Runnable 类注册

```javascript
// 引用：基于 Java.registerClass 的 Runnable 创建方式
Java.perform(function() {
    var Runnable = Java.use("java.lang.Runnable");

    // 动态创建一个实现了 Runnable 接口的类
    var MyRunnable = Java.registerClass({
        name: "com.roysue.myrunnable",
        implements: [Runnable],
        methods: {
            run: function() {
                console.log("MyRunnable is running in thread: " +
                    Java.use("java.lang.Thread").currentThread().getName());
            }
        }
    });

    // 创建实例并执行
    var runner = MyRunnable.$new();
    var Thread = Java.use("java.lang.Thread");
    var thread = Thread.$new(runner);
    thread.start();
});
```

### 3.2 含字段的 Runnable 类

```javascript
// 带字段的 Runnable，可以在不同方法间共享数据
Java.perform(function() {
    var Runnable = Java.use("java.lang.Runnable");

    var DataRunnable = Java.registerClass({
        name: "com.roysue.datarunnable",
        implements: [Runnable],
        fields: {
            data: "java.lang.String",
            counter: "int"
        },
        methods: {
            $init: [{
                returnType: "void",
                argumentTypes: ["java.lang.String"],
                implementation: function(data) {
                    this.data.value = data;
                    this.counter.value = 0;
                    console.log("DataRunnable created with: " + data);
                }
            }],
            run: function() {
                // 在 run 方法中使用字段
                this.counter.value++;
                console.log(
                    "run #" + this.counter.value +
                    ": data = " + this.data.value +
                    " in " + Java.use("java.lang.Thread").currentThread().getName()
                );
            }
        }
    });

    var runner = DataRunnable.$new("hello world");
    runner.run();  // 直接调用
});
```

### 3.3 构造函数重载

```javascript
Java.perform(function() {
    var Runnable = Java.use("java.lang.Runnable");

    var OverloadRunnable = Java.registerClass({
        name: "com.roysue.overloadrunnable",
        implements: [Runnable],
        fields: {
            message: "java.lang.String",
            delay: "long"
        },
        methods: {
            // 无参构造函数
            $init: [{
                returnType: "void",
                argumentTypes: [],
                implementation: function() {
                    this.message.value = "default";
                    this.delay.value = 0;
                }
            }],
            // 带参构造函数
            $init: [{
                returnType: "void",
                argumentTypes: ["java.lang.String", "long"],
                implementation: function(msg, delay) {
                    this.message.value = msg;
                    this.delay.value = delay;
                }
            }],
            run: function() {
                console.log("Message: " + this.message.value +
                    ", delay: " + this.delay.value);
            }
        }
    });

    // 使用不同的构造函数
    var r1 = OverloadRunnable.$new();
    var r2 = OverloadRunnable.$new("delayed", 5000);
    r1.run();
    r2.run();
});
```

## 4. 高级：综合 saveBitmap_3 中的注册模式

在 `hookBitmap.js` 的 `saveBitmap_3()` 函数中，有一个典型的高级注册模式：

```javascript
// 引用：Chap10/hookBitmap.js 第74-103行
var Runnable = Java.use("java.lang.Runnable");
var saveImg = Java.registerClass({
    name: "com.roysue.runnable",
    implements: [Runnable],
    fields: {
        bm: "android.graphics.Bitmap",
    },
    methods: {
        $init: [{
            returnType: "void",
            argumentTypes: ["android.graphics.Bitmap"],
            implementation: function (bitmap) {
                this.bm.value = bitmap;
            }
        }],
        run: function () {
            var path = "/sdcard/Download/tmp/" + guid() + ".jpg";
            console.log("path=> ", path);
            var file = Java.use("java.io.File").$new(path);
            var fos = Java.use("java.io.FileOutputStream").$new(file);
            this.bm.value.compress(
                Java.use("android.graphics.Bitmap$CompressFormat").JPEG.value,
                100,
                fos
            );
            console.log("success!");
            fos.flush();
            fos.close();
        }
    }
});
```

此模式的核心优势：
1. **字段传递对象**：将 `Bitmap` 对象存储在字段 `bm` 中
2. **异步执行**：`run()` 方法在独立线程中执行，不会阻塞 Hook 的原始调用
3. **类型安全**：所有字段和方法都有明确的 Java 类型签名

## 5. 实战场景：实现接口回调

```javascript
// 实现一个自定义的 Callback 接口
Java.perform(function() {
    // 假设目标应用定义了回调接口
    var Callback = Java.use("com.example.ICallback");

    var MyCallback = Java.registerClass({
        name: "com.roysue.mycallback",
        implements: [Callback],
        methods: {
            onSuccess: function(result) {
                console.log("Callback onSuccess: " + result);
                // 在这里可以进一步处理或调用其他方法
            },
            onError: function(code, msg) {
                console.log("Callback onError: code=" + code + ", msg=" + msg);
            }
        }
    });

    // 将自定义回调注入到目标类
    var TargetClass = Java.use("com.example.TargetClass");
    TargetClass.setCallback.implementation = function(callback) {
        console.log("Original callback registered, replacing with our callback");
        var myCallback = MyCallback.$new();
        this.setCallback(myCallback);  // 替换为自定义回调
    };
});
```

## 6. 注意事项

| 注意事项 | 说明 |
|:--------|:----|
| **类名冲突** | 自定义类名不要与目标应用已有的类名冲突，建议使用独特的包名前缀 |
| **生命周期** | 自定义类的实例在 JS 变量释放后可能被 GC 回收，需要保持引用 |
| **类型声明** | 字段和参数类型必须使用完整的 Java 类型字符串 |
| **线程安全** | 如果自定义类的方法会在多线程中被调用，需要注意同步问题 |
| **访问权限** | 自定义类不能访问目标应用中被 `private` 修饰的字段/方法 |

## 小结

- `Java.registerClass` 是 Frida 在运行时动态创建 Java 类的核心 API
- 典型应用场景包括：Runnable 回调注入、接口实现、对象字段传递
- `saveBitmap_3()` 中的 Runnable 注册模式展示了一个完整的实战案例：创建类、保存对象、在子线程中执行 IO 操作
- 结合字段和方法的重载支持，可以构造功能完整的 Java 类

> **参考源文件**：`Chap03/hello_world.js` 展示了 Java.use 类定位和基本调用模式；`Chap10/hookBitmap.js` 第74-103行的 `saveBitmap_3()` 展示了完整的 `Java.registerClass` 实战用法。
