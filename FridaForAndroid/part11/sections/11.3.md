# 11.3 加密算法实时追踪框架

> 核心要点：通过 Hook Java 加密 API 的核心类（SecretKeySpec、Cipher、MessageDigest、Mac、RSA），可以全方位追踪 App 的加密过程，捕获密钥、明文、密文、IV 向量、算法参数等关键数据。

## 1. Java 加密体系概览

Java 加密体系（JCA/JCE）的调用链通常为：

```java
// 对称加密（AES）典型调用链
// 1. 创建密钥
SecretKeySpec key = new SecretKeySpec(keyBytes, "AES");
// 2. 创建 IV
IvParameterSpec iv = new IvParameterSpec(ivBytes);
// 3. 获取 Cipher 实例
Cipher cipher = Cipher.getInstance("AES/CBC/PKCS5Padding");
// 4. 初始化（加密/解密模式 + 密钥 + IV）
cipher.init(Cipher.ENCRYPT_MODE, key, iv);
// 5. 执行加密/解密
byte[] result = cipher.doFinal(input);

// 哈希摘要
MessageDigest md = MessageDigest.getInstance("MD5");
md.update(data);
byte[] hash = md.digest();

// MAC 消息认证码
Mac mac = Mac.getInstance("HmacSHA256");
mac.init(key);
byte[] macResult = mac.doFinal(data);
```

**Hook 策略**：追踪上述调用链中的每一个步骤，即可捕获完整的加密过程信息。

### 2.2 堆栈追踪工具（第19-37行）

```javascript
// 引用：awesomeFrida/javaEnc.js 第19-37行
function showStacks() {
    var Exception = Java.use("java.lang.Exception");
    var ins = Exception.$new("Exception");
    var straces = ins.getStackTrace();
    if (undefined == straces || null == straces) {
        return;
    }
    klog("============================= Stack strat=======================");
    for (var i = 0; i < straces.length; i++) {
        var str = "   " + straces[i].toString();
        klog(str);
    }
    klog("============================= Stack end=======================\r\n");
    Exception.$dispose();
}
```

通过在 Hook 点创建 Java Exception 对象，获取当前调用堆栈，帮助定位加密操作的调用来源。

### 2.3 编码转换工具函数库（第40-237行）

javaEnc.js 提供了丰富的编码转换函数，用于在各种格式之间转换加密数据：

| 函数名 | 功能 | 输入 | 输出 |
|:---:|:---|:---|:---|
| `stringToBase64()` | 字符串→Base64 | String | Base64 String |
| `base64ToString()` | Base64→字符串 | Base64 String | String |
| `hexToBase64()` | Hex→Base64 | Hex String | Base64 String |
| `base64ToHex()` | Base64→Hex | Base64 String | Hex String |
| `hexToBytes()` | Hex→字节数组 | Hex String | Number[] |
| `bytesToHex()` | 字节数组→Hex | Number[] | Hex String |
| `stringToHex()` | 字符串→Hex | String | Hex String |
| `stringToBytes()` | 字符串→字节数组 | String | Number[] |
| `bytesToString()` | 字节数组→字符串 | Number[] | String |
| `bytesToBase64()` | 字节数组→Base64 | Number[] | Base64 String |
| `base64ToBytes()` | Base64→字节数组 | Base64 String | Number[] |

```javascript
// 引用：awesomeFrida/javaEnc.js 第169-176行 —— bytesToString 实现
function bytesToString(arr) {
    var str = '';
    arr = new Uint8Array(arr);
    for (var i in arr) {
        str += String.fromCharCode(arr[i]);
    }
    return str;
}

// 引用：awesomeFrida/javaEnc.js 第128-143行 —— bytesToHex 实现
function bytesToHex(arr) {
    var str = '';
    var k, j;
    for (var i = 0; i < arr.length; i++) {
        k = arr[i];
        j = k;
        if (k < 0) {
            j = k + 256;
        }
        if (j < 16) {
            str += "0";
        }
        str += j.toString(16);
    }
    return str;
}
```

### 2.4 SecretKeySpec / DESKeySpec 密钥追踪（第242-271行）

```javascript
// 引用：awesomeFrida/javaEnc.js 第242-250行
var secretKeySpec = Java.use('javax.crypto.spec.SecretKeySpec');
secretKeySpec.$init.overload('[B', 'java.lang.String').implementation = function (a, b) {

// 引用：awesomeFrida/javaEnc.js 第252-271行 —— DESKeySpec 两个重载
var DESKeySpec = Java.use('javax.crypto.spec.DESKeySpec');
DESKeySpec.$init.overload('[B').implementation = function (a) {
    showStacks();
    var result = this.$init(a);
    klog("======================================");
    var bytes_key_des = this.getKey();

```

**捕获的信息**：通过 Hook `SecretKeySpec` 构造函数，可以捕获：
- 加密算法名称（AES、DES、Blowfish 等）
- 密钥的字符串表示和 Hex 编码

### 2.5 Mac 消息认证码追踪（第273-311行）

```javascript
// 引用：awesomeFrida/javaEnc.js 第273-311行
var mac = Java.use('javax.crypto.Mac');
mac.getInstance.overload('java.lang.String').implementation = function (a) {
    showStacks();
    var result = this.getInstance(a);
    klog("======================================");
    klog("算法名：" + a);
    return result;
}
mac.update.overload('[B').implementation = function (a) {
    this.update(a);
    klog("======================================");
    klog("update:" + bytesToString(a))
}
mac.doFinal.overload().implementation = function () {
    var result = this.doFinal();
    klog("======================================");
    klog("doFinal结果: |str  :" + bytesToString(result));
    klog("doFinal结果: |hex  :" + bytesToHex(result));
    klog("doFinal结果: |base64  :" + bytesToBase64(result));
    return result;
}
```

**追踪维度**：
- `getInstance`：捕获算法名（HmacSHA256、HmacMD5 等）
- `update`：捕获每次更新的输入数据
- `doFinal`：捕获最终 MAC 值（str/hex/base64 三种格式）

### 2.6 MessageDigest 哈希摘要追踪（第313-354行）

```javascript
// 引用：awesomeFrida/javaEnc.js 第313-354行
var md = Java.use('java.security.MessageDigest');
md.getInstance.overload('java.lang.String').implementation = function (a) {

}
md.update.overload('[B').implementation = function (a) {
    klog("======================================");

}
md.digest.overload().implementation = function () {
    klog("======================================");
    var result = this.digest();
    klog("digest结果:" + bytesToHex(result));
    klog("digest结果:" + bytesToBase64(result));
    return result;
}
md.digest.overload('[B').implementation = function (a) {
    klog("======================================");
    klog("digest参数:" + bytesToString(a));

    klog("digest结果:" + bytesToHex(result));
    klog("digest结果:" + bytesToBase64(result));

```

支持 MD5、SHA-1、SHA-256、SHA-512 等所有摘要算法，捕获 update 的输入数据和 digest 的哈希结果。

### 2.8 Cipher 核心加密器追踪（第366-542行）

Cipher 的追踪是 javaEnc.js 中最复杂的部分，涵盖 getInstance、多个重载的 init、update、doFinal：

```javascript
// 引用：awesomeFrida/javaEnc.js 第366-542行
var cipher = Java.use('javax.crypto.Cipher');

// getInstance —— 捕获加密模式和填充方式
cipher.getInstance.overload('java.lang.String').implementation = function (a) {
    var result = this.getInstance(a);
    klog("======================================");
    klog("模式填充:" + a);  // 例如 "AES/CBC/PKCS5Padding"
    return result;
}

// init —— 捕获密钥、模式（加密/解密）
cipher.init.overload('int', 'java.security.Key').implementation = function (a, b) {
    var result = this.init(a, b);
    if (N_ENCRYPT_MODE == a) {
        klog("init  | 加密模式");
    } else if (N_DECRYPT_MODE == a) {
        klog("init  | 解密模式");
    }
    var bytes_key = b.getEncoded();
    klog("init key: |str密钥:" + bytesToString(bytes_key));
    klog("init key: |Hex密钥:" + bytesToHex(bytes_key));
    return result;
}

// doFinal —— 捕获加密/解密结果
cipher.doFinal.overload('[B').implementation = function (a) {
    var result = this.doFinal(a);
    klog("doFinal参数: |str  :" + bytesToString(a));
    klog("doFinal结果: |str  :" + bytesToString(result));
    klog("doFinal结果: |hex  :" + bytesToHex(result));
    klog("doFinal结果: |base64  :" + bytesToBase64(result));
    return result;
}
```

javaEnc.js 共 Hook 了 Cipher.init 的 **8 个重载版本**，覆盖所有可能的 Java 加密初始化场景：

| 重载签名 | 参数说明 |
|:---|:---|
| `init(int, Key)` | 仅密钥，无 IV |
| `init(int, Certificate)` | 使用证书初始化 |
| `init(int, Key, AlgorithmParameterSpec)` | 密钥 + IV/Spec |
| `init(int, Certificate, SecureRandom)` | 证书 + 随机数 |
| `init(int, Key, SecureRandom)` | 密钥 + 随机数 |
| `init(int, Key, AlgorithmParameters)` | 密钥 + 算法参数 |
| `init(int, Key, AlgorithmParameters, SecureRandom)` | 密钥 + 算法参数 + 随机数 |
| `init(int, Key, AlgorithmParameterSpec, SecureRandom)` | 密钥 + IV/Spec + 随机数 |

## 4. 扩展：自定义 Python 客户端

```python
import frida
import json

def on_message(message, data):
    if message['type'] == 'send':
        msg = message['payload']
        if isinstance(msg, str):
            print(msg)
        elif isinstance(msg, dict) and msg.get('jsname') == 'javaEnc':
            # 结构化处理 javaEnc 消息
            print(f"[{msg.get('data', '')}]")

device = frida.get_usb_device()
session = device.attach("com.example.app")

with open("javaEnc.js") as f:
    script = session.create_script(f.read())

script.on("message", on_message)
script.load()
input()
```

## 5. 加密追踪框架总结

| Hook 点 | 捕获信息 | 典型用途 |
|:---|:---|:---|
| `SecretKeySpec.$init` | 算法名、密钥（str/hex） | 获取对称加密密钥 |
| `IvParameterSpec.$init` | IV 向量 | 解密依赖 IV 的加密数据 |
| `Cipher.getInstance` | 算法模式填充 | 了解加密方式 |
| `Cipher.init` | 加密/解密模式、密钥 | 明确操作方向 |
| `Cipher.doFinal` | 明文/密文数据 | 获取加密结果 |
| `MessageDigest` | 哈希输入输出 | 追踪签名/校验过程 |
| `Mac` | MAC 值 | 追踪消息认证过程 |
| `X509EncodedKeySpec` | RSA 公钥 | 获取非对称密钥 |
| `KeyPairGenerator` | 生成的密钥对 | 捕获动态生成的密钥 |
| `RSAPublicKeySpec` | RSA N 和 E 参数 | 捕获 RSA 参数 |

> **参考源文件**：`awesomeFrida/javaEnc.js`（完整592行代码）实现了上述所有 Hook 点，是目前最完整的 Java 加密算法实时追踪框架。
