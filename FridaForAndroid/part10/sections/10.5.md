# 10.5 360 加固分析与脱壳

> 核心要点：360 加固（Qihoo 360）是国内最常见的 Android 应用加固方案之一。它采用 DEX 加壳 + SO 加固 + 反调试的多层保护策略。本节深入分析 360 加固的特征识别、字符串解密方案和 DEX 脱壳技巧。

## 1. 360 加固概述

### 1.1 加固方案特征

```xml
<!-- 360 加固后的 AndroidManifest.xml 特征 -->
<application 
    android:name="com.stub.StubApp"  <!-- ← 关键特征 -->
    ...>

<!-- 360 加固后的关键类 -->
com.stub.StubApp          <!-- 应用入口，继承 Application -->
com.qihoo.util.StubApp    <!-- 另一种入口类名 -->
com.qihoo360.stub         <!-- 360 桩包 -->

<!-- 加固后的 native 库 -->
libjiagu.so        <!-- 360 加固核心 SO -->
libjiagu_art.so    <!-- ART 相关 -->
libjiagu_x86.so    <!-- x86 兼容 -->
libjiagu_64.so     <!-- 64位 -->
```

### 1.2 加固层级

```
第一层：DEX 加壳
    └── 原始 DEX 被加密压缩存放在 assets 或 res 中
    └── 运行时由壳解密并动态加载

第二层：SO 加固
    └── libjiagu.so 自身被加固
    └── ELF section header 被抹除
    └── 关键函数被加密

第三层：反调试
    └── ptrace 反调试
    └── /proc/pid/status 检测
    └── TracerPid 检测
    └── 端口扫描检测 frida-server
    └── init_array 中启动反调试线程

第四层：字符串加密
    └── 关键字符串在 native 层加密
    └── 通过 StubApp.getString2() 解密
```

## 2. 360 加固字符串解密

### 2.1 完整解密脚本

```javascript
// 引用：awesomeFrida/360getString.js（完整98行代码）
// 
// 功能：调用 360 加固的 StubApp.getString2 方法解密字符串
// 360 加固将关键字符串（URL、密钥、类名等）在 native 层加密
// 运行时通过 StubApp.getString2(密文) 解密

// ==========================================
// 360 加固字符串解密工具
// ==========================================

function decode360String(s){
    if (!s) {
        console.log('请输入360加固的密文字符串!');
        return;
    }
        
    Java.perform(function(){
        try {
            // 引用：StubApp 是 360 加固的核心桩类
            // getString2 是 360 加固的字符串解密方法
            var Class = Java.use('com.stub.StubApp');
            var result = Class.getString2(s);
            console.log('解密结果: ' + result);
            return result;
        } catch(e) {
            console.log('[-] 解密失败: ' + e);
            console.log('[-] 可能是 getString2 方法名不同，尝试其他名称...');
            tryDecodeAlternatives(s);
        }
    });
}

// 备选解密方案：尝试其他可能的方法名
function tryDecodeAlternatives(encryptedStr) {
    var candidates = [
        'com.stub.StubApp',
        'com.qihoo.util.StubApp',
        'com.qihoo360.stub.StubApp',
        'com.qihoo.util.ReflectUtil',
    ];
    
    var methods = ['getString2', 'getString', 'decode', 'decrypt', 'd'];
    
    candidates.forEach(function(className) {
        try {
            var clz = Java.use(className);
            methods.forEach(function(methodName) {
                try {
                    var result = clz[methodName](encryptedStr);
                    if (result && result.length > 0) {
                        console.log('[+] 使用 ' + className + '.' + 
                                   methodName + ' 解密成功: ' + result);
                    }
                } catch(e) {}
            });
        } catch(e) {}
    });
}

// 搜索内存中的 360 加固字符串解密方法
function find360DecryptMethod() {
    Java.perform(function() {
        var targetClass = Java.use('com.stub.StubApp');
        // 获取类的所有方法
        var methods = targetClass.class.getDeclaredMethods();
        console.log('[*] StubApp 方法列表:');
        methods.forEach(function(method) {
            console.log('  - ' + method.getName() + 
                       ' ' + method.getReturnType().getName() +
                       ' params: ' + method.getParameterTypes().length);
        });
    });
}

// 批量解密：解密一批预定义的密文字符串
function batchDecrypt360(encryptedStrings) {
    Java.perform(function() {
        var StubApp = Java.use('com.stub.StubApp');
        encryptedStrings.forEach(function(s, index) {
            try {
                var result = StubApp.getString2(s);
                console.log('[' + index + '] ' + s + ' → ' + result);
            } catch(e) {
                console.log('[' + index + '] ' + s + ' → [解密失败]');
            }
        });
    });
}

// Hook getString2 以捕获所有解密调用
function hook360Decrypt() {
    Java.perform(function() {
        var StubApp = Java.use('com.stub.StubApp');
        var getString2 = StubApp.getString2.overload('java.lang.String');
        
        getString2.implementation = function(encrypted) {
            var result = this.getString2(encrypted);
            console.log('[360Decrypt] ' + encrypted + ' → ' + result);
            return result;
        };
        
        console.log('[+] Hooked StubApp.getString2');
    });
}

// 使用示例:
// decode360String("U2FsdGVkX1+xxx...")  // 解密单个字符串
// hook360Decrypt()                       // Hook 所有解密调用
// ==========================================
```

### 2.2 getString2 调用时机

360 加固在以下场景调用 `getString2`：
1. **网络请求 URL**：加密的 API 端点地址
2. **ClassLoader 路径**：加密的 DEX 加载路径
3. **反射调用类名**：隐藏关键类的全限定名
4. **关键字符串常量**：AES 密钥、iv 向量等

```javascript
// Hook getString2 的输出示例
[360Decrypt] U2FsdGVkX18E3W0l... → https://api.example.com/v1/data
[360Decrypt] U2FsdGVkX18Rt7P... → /data/data/com.example/app_dex/classes.dex
[360Decrypt] U2FsdGVkX18Kf2N... → com.example.core.CryptEngine
[360Decrypt] U2FsdGVkX18A9mH... → AES/CBC/PKCS5Padding
```

## 3. 360 加固 DEX 脱壳

### 3.1 脱壳流程

```
1. 启动目标 App（确保 360 壳完成初始化）
2. 搜索内存中的 DEX 魔数
3. 对找到的 DEX 进行完整性和合法性验证
4. dump 符合要求的 DEX 文件
5. 使用 baksmali 或 jadx 分析 dump 出的 DEX
```

### 3.2 专用脱壳脚本

```javascript
// 360 加固专用 DEX 脱壳脚本
'use strict';

function dump360Dex() {
    // 360 壳完成初始化的典型延时
    var delays = [3000, 5000, 8000, 12000];
    
    delays.forEach(function(delay) {
        setTimeout(function() {
            console.log("[*] Scanning at " + delay + "ms...");
            scanAndDump();
        }, delay);
    });
}

function scanAndDump() {
    var magics = [
        "64 65 78 0A 30 33 35 00",
        "64 65 78 0A 30 33 37 00", 
        "64 65 78 0A 30 33 38 00",
        "64 65 78 0A 30 33 39 00",
    ];
    
    var count = 0;
    
    Process.enumerateRanges('rw-').forEach(function(range) {
        magics.forEach(function(magic) {
            try {
                var results = Memory.scanSync(range.base, range.size, magic);
                results.forEach(function(match) {
                    var addr = match.address;
                    var fileSize = addr.add(0x20).readU32();
                    var classDefsSize = addr.add(0x58).readU32();
                    
                    // 360 加固的 DEX 通常较大（> 100KB）
                    if (fileSize > 102400 && classDefsSize > 0) {
                        count++;
                        var dumpPath = "/data/local/tmp/360_dex_" + 
                                      count + "_" + 
                                      addr.toString(16) + "_" + 
                                      fileSize + ".dex";
                        
                        try {
                            Memory.protect(addr, fileSize, 'rwx');
                        } catch(e) {}
                        
                        var buffer = addr.readByteArray(fileSize);
                        var file = new File(dumpPath, "wb");
                        file.write(buffer);
                        file.flush();
                        file.close();
                        console.log("[+] DEX #" + count + ": " + dumpPath);
                        console.log("    size: " + fileSize + 
                                   " classes: " + classDefsSize);
                    }
                });
            } catch(e) {}
        });
    });
    
    if (count === 0) {
        console.log("[-] No DEX found in this scan");
    }
}

// 同时 hook dlopen 观察 360 壳的 SO 加载
function monitor360Libs() {
    var libs = ["libjiagu", "libjiagu_art", "libjiagu_64"];
    
    ["dlopen", "android_dlopen_ext"].forEach(function(fn) {
        var addr = Module.findExportByName(null, fn);
        if (addr) {
            Interceptor.attach(addr, {
                onEnter: function(args) {
                    var libName = ptr(args[0]).readCString();
                    libs.forEach(function(lib) {
                        if (libName.indexOf(lib) >= 0) {
                            console.log("[360] Loading: " + libName);
                        }
                    });
                }
            });
        }
    });
}

// 运行
setImmediate(function() {
    console.log("[*] 360 加固脱壳脚本启动");
    monitor360Libs();
    dump360Dex();
});
```

## 4. 360 加固 SO 脱壳

### 4.1 识别 libjiagu.so

```javascript
// 获取 libjiagu.so 的模块信息
function inspectJiagu() {
    var module = Process.findModuleByName("libjiagu.so");
    if (!module) {
        console.log("[-] libjiagu.so not found");
        return;
    }
    
    console.log("[+] libjiagu.so:");
    console.log("  base: " + module.base);
    console.log("  size: " + ptr(module.size));
    console.log("  path: " + module.path);
    
    // 检查 ELF header
    var magic = module.base.readCString(4);
    console.log("  ELF magic: " + magic);
    
    // 检查 section header 是否被抹除
    var e_shoff = module.base.add(0x20).readU32();  // 64-bit
    if (e_shoff === 0) {
        console.log("  [!!!] Section headers stripped");
    } else {
        console.log("  shoff: " + e_shoff);
    }
    
    // 枚举导出符号
    try {
        var exports = module.enumerateExports();
        console.log("  exports: " + exports.length);
        exports.slice(0, 10).forEach(function(exp) {
            console.log("    " + exp.name + " @ " + exp.address);
        });
    } catch(e) {
        console.log("  enumerateExports failed: " + e);
    }
}
```

### 4.2 Dump libjiagu.so

```javascript
// 引用：awesomeFrida/dump_so.js（51行完整代码）
function dump_so(so_name) {
    Java.perform(function () {
        var currentApplication = Java.use("android.app.ActivityThread")
            .currentApplication();
        var dir = currentApplication.getApplicationContext()
            .getFilesDir().getPath();
        var libso = Process.getModuleByName(so_name);
        console.log("[name]:", libso.name);
        console.log("[base]:", libso.base);
        console.log("[size]:", ptr(libso.size));
        console.log("[path]:", libso.path);
        var file_path = dir + "/" + libso.name + "_" + 
                       libso.base + "_" + ptr(libso.size) + ".so";
        var file_handle = new File(file_path, "wb");
        if (file_handle && file_handle != null) {
            Memory.protect(ptr(libso.base), libso.size, 'rwx');
            var libso_buffer = ptr(libso.base).readByteArray(libso.size);
            file_handle.write(libso_buffer);
            file_handle.flush();
            file_handle.close();
            console.log("[dump]:", file_path);
        }
    });
}

// 运行：frida -U com.example.app -l dump_so.js
// 脚本自动 dump libshield.so（可替换为 libjiagu.so）
```

## 5. 绕过 360 反调试

### 5.1 TracerPid 检测绕过

```javascript
// 360 加固通过读取 /proc/self/status 的 TracerPid 
// 检测是否被调试（Frida 注入时 TracerPid > 0）

function bypassTracerPid() {
    // Hook fopen，当打开 /proc/self/status 时返回伪造内容
    var fopenAddr = Module.findExportByName("libc.so", "fopen");
    
    Interceptor.attach(fopenAddr, {
        onEnter: function(args) {
            var path = ptr(args[0]).readCString();
            if (path && path.indexOf("status") >= 0) {
                console.log("[anti] fopen(" + path + ") intercepted");
                // 可以在这里返回一个伪造的文件句柄
            }
        }
    });
    
    // Hook fgets，当读取 TracerPid 行时修改内容
    var fgetsAddr = Module.findExportByName("libc.so", "fgets");
    
    Interceptor.attach(fgetsAddr, {
        onLeave: function(retval) {
            if (retval.isNull()) return;
            try {
                var content = retval.readCString();
                if (content && content.indexOf("TracerPid:") >= 0) {
                    // 在返回前修改内容
                    var fakeLine = Memory.allocUtf8String("TracerPid:\t0\n");
                    retval = fakeLine;
                    console.log("[anti] TracerPid modified to 0");
                }
            } catch(e) {}
        }
    });
}
```

### 5.2 ptrace 检测绕过

```javascript
// 360 加固可能使用 ptrace 检测是否已被附加
// 绕过方式：Hook ptrace 函数

function bypassPtrace() {
    var ptraceAddr = Module.findExportByName("libc.so", "ptrace");
    if (!ptraceAddr) return;
    
    Interceptor.attach(ptraceAddr, {
        onEnter: function(args) {
            var request = args[0].toInt32();
            // PTRACE_TRACEME = 0, PTRACE_ATTACH = 16
            if (request === 0 || request === 16) {
                console.log("[anti] ptrace(" + request + 
                          ", " + args[1] + ") intercepted");
                // PTRACE_TRACEME 返回 -1 表示失败
                // 但壳可能通过返回值判断
            }
        },
        onLeave: function(retval) {
            // 可以修改返回值让壳误以为 ptrace 成功
        }
    });
}
```

## 6. 实战：360 加固应用完整脱壳步骤

### 6.1 环境准备

```bash
# 1. 确认目标应用使用 360 加固
# 解压 APK，检查是否存在以下特征
unzip -l target.apk | grep -E "libjiagu|StubApp"

# 2. 启动 frida-server（使用非默认端口绕过端口检测）
adb shell
su
/data/local/tmp/frida-server -l 0.0.0.0:12345 &

# 3. 在 PC 端连接
frida -H 192.168.1.100:12345 -U com.example.app -l script.js
```

### 6.2 脱壳步骤

```bash
# 步骤一：先运行字符串解密脚本，了解应用的关键信息
frida -U com.example.app -l 360getString.js
# 在 Frida 控制台调用: decode360String("密文字符串")

# 步骤二：Hook getString2 捕获所有解密调用
# 这可以帮助定位 DEX 加载路径和关键类名

# 步骤三：运行 DEX dump 脚本
frida -U com.example.app -l dump360_dex.js

# 步骤四：dump libjiagu.so
frida -U com.example.app -l dump_so.js
# 注意修改脚本中的 so_name 为 "libjiagu.so"

# 步骤五：使用 jadx 或 baksmali 分析 dump 出的 DEX
java -jar baksmali.jar d 360_dex_1_*.dex -o smali_out/
jadx-gui 360_dex_1_*.dex
```

### 6.3 验证结果

```bash
# 检查是否成功脱壳
dexdump -d dumped.dex | grep "Lcom/example/app/MainActivity;"

# 如果看到原始的包名和类名，说明脱壳成功
# 如果只有 com.stub.StubApp 相关类，说明脱壳失败
```

## 总结

- **360 加固特征**：`com.stub.StubApp` 入口类、`libjiagu.so` 系列 SO 文件
- **字符串解密**：通过 `StubApp.getString2()` 解密加密字符串，Hook 该函数可捕获所有解密数据
- **DEX 脱壳**：360 加固的 DEX 会在内存中以标准格式存在，搜索魔数即可 dump
- **SO 脱壳**：`dump_so()` 脚本可以直接从内存提取 libjiagu.so
- **反调试绕过**：需要处理 TracerPid 检测、ptrace 检测和端口扫描
- **推荐方案**：延迟扫描 + Hook getString2 定位 DEX + 多时间点 dump
