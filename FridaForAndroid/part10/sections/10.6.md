# 10.6 Dump Lua 脚本

> 核心要点：大量 Android 游戏使用 Cocos2d-x 引擎，其核心游戏逻辑以 Lua 脚本编写。为了保护知识产权，开发者通常对 Lua 脚本进行加密（XXTEA 加密或自定义加密），运行时由游戏引擎解密加载。通过 Hook 引擎的关键加载函数，可以 dump 出解密后的原始 Lua 脚本。

## 1. Cocos2d-x Lua 脚本加载流程

### 1.1 标准加载链

```
游戏启动
    ↓
libgame.so / libcocos2dlua.so 被加载
    ↓
Cocos2d-x 引擎初始化
    ↓
调用脚本加载函数读取 .lua / .luac 文件
    ↓
解密（如果加密）：先解密得到 Lua 源码或字节码
    ↓
★★★ 关键点：将解密后的内容传给 luaL_loadbuffer ★★★
    ↓
Lua 虚拟机编译并执行脚本
```

### 1.2 关键的 Hook 点

| 函数 | 所在 SO | 参数 | 说明 |
|------|---------|------|------|
| **luaL_loadbuffer** | libcocos2dlua.so / libgame.so | (L, data, size, name) | 加载 Lua 字节码的入口 |
| **luaL_loadstring** | libcocos2dlua.so | (L, string) | 加载 Lua 源码字符串 |
| **luaL_loadfile** | libcocos2dlua.so | (L, filename) | 从文件加载 Lua |
| **CCFileUtils::getFileData** | libgame.so / libcocos2d.so | (path, mode, size) | 读取文件内容（含解密） |
| **CCFileUtils::getFileDataFromZip** | libgame.so | (zip, path, size) | 从 ZIP 包中读取文件 |
| **fopen** | libc.so | (path, mode) | 文件打开（通用） |
| **xxtea_decrypt** | libcocos2dlua.so | (data, len, key, keylen, outlen) | XXTEA 解密函数 |

## 2. 通过 luaL_loadbuffer Hook 获取 Lua 脚本

### 2.1 基础 Hook 脚本

```javascript
// Hook luaL_loadbuffer 以 dump 所有通过它加载的 Lua 脚本
// luaL_loadbuffer 是 Lua C API，用于加载 Lua 字节码

function hookLuaLoadBuffer() {
    var targetLib = "libgame.so";  // 根据实际游戏修改
    var addr = Module.findExportByName(targetLib, "luaL_loadbuffer");
    
    if (!addr) {
        console.log("[-] luaL_loadbuffer not found in " + targetLib);
        // 尝试其他可能的 SO
        var modules = ["libcocos2dlua.so", "libcocos2d.so", "libxgame.so"];
        modules.forEach(function(m) {
            var a = Module.findExportByName(m, "luaL_loadbuffer");
            if (a) {
                console.log("[+] Found luaL_loadbuffer in " + m + " @ " + a);
                installHook(m, a);
            }
        });
        return;
    }
    
    installHook(targetLib, addr);
}

function installHook(libName, addr) {
    // luaL_loadbuffer 签名:
    // int luaL_loadbuffer(lua_State* L, const char* buff, size_t sz, const char* name)
    // 参数: args[0]=L, args[1]=buff(数据), args[2]=sz(大小), args[3]=name(名称)
    
    var counter = 0;
    
    Interceptor.attach(addr, {
        onEnter: function(args) {
            var name = ptr(args[3]).readCString();
            var size = args[2].toInt32();
            
            // 只 dump Lua 脚本（通常有 .lua 后缀或特定前缀）
            if (name && name.indexOf(".lua") >= 0 || 
                (name && size > 100 && size < 1048576)) {
                
                counter++;
                console.log("[luaL_loadbuffer] Loading: " + name + 
                           " size: " + size);
                
                try {
                    var data = ptr(args[1]).readByteArray(size);
                    var filename = "/data/local/tmp/lua_" + 
                                  (name.split("/").pop() || counter) + 
                                  "_" + counter + ".lua";
                    
                    var file = new File(filename, "wb");
                    file.write(data);
                    file.flush();
                    file.close();
                    console.log("[+] Saved: " + filename + 
                               " (" + size + " bytes)");
                    
                    // 尝试以字符串形式输出前 200 字节
                    try {
                        var preview = ptr(args[1]).readCString();
                        if (preview && preview.length > 0) {
                            console.log("[Preview] " + 
                                       preview.substring(0, 200));
                        }
                    } catch(e) {}
                    
                } catch(e) {
                    console.log("[-] Save failed: " + e);
                }
            }
        }
    });
    
    console.log("[+] Hooked luaL_loadbuffer in " + libName);
}

setImmediate(hookLuaLoadBuffer);
```

### 2.2 完整 Lua Dump 脚本（含多种 Hook 策略）

```javascript
// 引用：awesomeFrida/MT.js（262行）中的 Lua Dump 方案
// 
// 完整 Lua 脚本提取工具：同时 Hook 多种 Lua 加载途径

'use strict';

var PACKAGENAME = "com.example.game";
var SAVEDIR = "lua_dump";

// 获取应用私有目录
function getSaveDir() {
    var dir = "/sdcard/" + SAVEDIR + "/";
    return dir;
}

// 保存数据到文件
function save2File(filename, bytes) {
    console.log("[save] " + filename);
    var file = new File(filename, "wb");
    file.write(bytes);
    file.flush();
    file.close();
}

// ==========================================
// 策略一：Hook getFileData 读取文件数据
// ==========================================
function hookGetFileData() {
    // CCFileUtils::getFileData 的 C++ 符号
    var symbols = [
        "_ZN7cocos2d11CCFileUtils11getFileDataEPKcS2_Pmb",
        "_ZN7cocos2d11CCFileUtils11getFileDataERKNSt6..."
    ];
    
    var modules = Process.enumerateModules();
    modules.forEach(function(m) {
        if (m.name.indexOf("libgame") >= 0 || 
            m.name.indexOf("libcocos2d") >= 0) {
            
            symbols.forEach(function(sym) {
                try {
                    var exports = m.enumerateExports();
                    exports.forEach(function(exp) {
                        if (exp.name.indexOf("getFileData") >= 0) {
                            console.log("[+] getFileData found in " + 
                                       m.name + " @ " + exp.address);
                            
                            Interceptor.attach(exp.address, {
                                onEnter: function(args) {
                                    try {
                                        var path = ptr(args[1]).readCString();
                                        if (path && (path.indexOf(".lua") >= 0 || 
                                            path.indexOf(".luac") >= 0)) {
                                            this.filePath = path;
                                            this.sizePtr = ptr(args[3]);
                                            console.log("[getFileData] " + path);
                                        }
                                    } catch(e) {}
                                },
                                onLeave: function(retval) {
                                    if (this.filePath && !retval.isNull()) {
                                        var size = this.sizePtr.readU32();
                                        if (size > 0 && size < 10485760) {
                                            var data = ptr(retval).readByteArray(size);
                                            var name = this.filePath.split("/").pop();
                                            var path = getSaveDir() + 
                                                      this.filePath.split("/").join("_");
                                            save2File(path, data);
                                        }
                                    }
                                }
                            });
                        }
                    });
                } catch(e) {}
            });
        }
    });
}

// ==========================================
// 策略二：Hook luaL_loadbuffer（主策略）
// ==========================================
function hookLuaLoadBuffer() {
    var modules = ["libgame.so", "libcocos2dlua.so", 
                   "libcocos2d.so", "libxgame.so"];
    
    modules.forEach(function(modName) {
        var mod = Process.findModuleByName(modName);
        if (!mod) return;
        
        // 搜索 luaL_loadbuffer
        var exports = mod.enumerateExports();
        exports.forEach(function(exp) {
            if (exp.name.indexOf("luaL_loadbuffer") >= 0) {
                console.log("[+] luaL_loadbuffer in " + modName + " @ " + exp.address);
                
                Interceptor.attach(exp.address, {
                    onEnter: function(args) {
                        // luaL_loadbuffer(L, buff, size, name)
                        try {
                            var name = ptr(args[3]).readCString();
                            var size = args[2].toInt32();
                            
                            if (name && size > 0 && size < 10485760) {
                                console.log("[luaL_loadbuffer] name: " + name + 
                                           " size: " + size);
                                
                                var data = ptr(args[1]).readByteArray(size);
                                var saveName = name.split("/").pop() + ".lua";
                                var path = getSaveDir() + saveName;
                                save2File(path, data);
                            }
                        } catch(e) {}
                    }
                });
            }
        });
    });
}

// ==========================================
// 策略三：Hook fopen 监控 .lua 文件访问
// ==========================================
function hookFopen() {
    var fopenAddr = Module.findExportByName("libc.so", "fopen");
    if (!fopenAddr) return;
    
    Interceptor.attach(fopenAddr, {
        onEnter: function(args) {
            var path = ptr(args[0]).readCString();
            if (path && (path.indexOf(".lua") >= 0 || 
                path.indexOf(".luac") >= 0)) {
                console.log("[fopen] " + path);
                // 记录调用栈
                console.log(Thread.backtrace(this.context, Backtracer.ACCURATE)
                    .map(DebugSymbol.fromAddress).join('\n'));
            }
        }
    });
}

// ==========================================
// 策略四：Hook XXTEA 解密函数
// ==========================================
function hookXXTEA() {
    var modules = ["libgame.so", "libcocos2dlua.so"];
    
    modules.forEach(function(modName) {
        var mod = Process.findModuleByName(modName);
        if (!mod) return;
        
        mod.enumerateExports().forEach(function(exp) {
            // XXTEA 相关符号
            if (exp.name.indexOf("xxtea") >= 0 || 
                exp.name.indexOf("XXTEA") >= 0) {
                console.log("[XXTEA] " + exp.name + " @ " + exp.address);
            }
        });
    });
}

// ==========================================
// 策略五：Hook DoFile 等引擎级函数
// ==========================================
function hookDoFile() {
    // Cocos2d-x LuaEngine::executeString / executeScriptFile
    var symbols = [
        "_ZN7cocos2d11CCLuaEngine13executeStringEPKc",
        "_ZN7cocos2d11CCLuaEngine15executeScriptFileEPKc",
    ];
    
    var modules = Process.enumerateModules();
    modules.forEach(function(m) {
        if (m.name.indexOf("libgame") >= 0 || 
            m.name.indexOf("libcocos2d") >= 0) {
            
            try {
                m.enumerateExports().forEach(function(exp) {
                    if (exp.name.indexOf("CCLuaEngine") >= 0) {
                        if (exp.name.indexOf("executeString") >= 0 ||
                            exp.name.indexOf("executeScript") >= 0 ||
                            exp.name.indexOf("DoFile") >= 0) {
                            
                            console.log("[LuaEngine] " + exp.name + 
                                       " @ " + exp.address);
                            
                            Interceptor.attach(exp.address, {
                                onEnter: function(args) {
                                    var name = ptr(args[1]).readCString();
                                    console.log("[DoFile] " + name);
                                }
                            });
                        }
                    }
                });
            } catch(e) {}
        }
    });
}

// ==========================================
// 主入口
// ==========================================
function main() {
    console.log("[*] Lua Dump Script Loaded");
    console.log("[*] Target package: " + PACKAGENAME);
    console.log("[*] Save dir: " + getSaveDir());
    
    // 启动所有 Hook 策略
    hookGetFileData();      // 策略一：文件读取
    hookLuaLoadBuffer();   // 策略二：luaL_loadbuffer
    hookFopen();            // 策略三：文件打开
    hookXXTEA();            // 策略四：XXTEA 解密
    hookDoFile();           // 策略五：引擎级加载
    
    console.log("[*] All hooks installed, waiting for Lua scripts...");
}

setImmediate(main);
```

## 3. Lua 脚本加密处理

### 3.1 XXTEA 加密识别

XXTEA（Corrected Block TEA）是 Cocos2d-x 默认的 Lua 脚本加密方案：

```cpp
// Cocos2d-x 中的 XXTEA 加密调用
// 加密后的 .luac 文件会进行 XXTEA 加密
// 密钥通常定义为固定字符串

// cocos2d-x/tools/cocos2d-console/plugins/plugin_compile_scripts.py
// 中定义的默认密钥：key = "2dxLua"
// 但大部分游戏会修改为自定义密钥

// xxtea_decrypt 函数签名
unsigned char* xxtea_decrypt(
    unsigned char* data,    // 加密数据
    size_t len,             // 数据长度
    unsigned char* key,     // 密钥
    size_t key_len,         // 密钥长度
    size_t* out_len         // 输出长度
);
```

### 3.2 获取 XXTEA 密钥

```javascript
// Hook 获取 XXTEA 密钥
function captureXXTEAKey() {
    var modules = ["libgame.so", "libcocos2dlua.so"];
    
    modules.forEach(function(modName) {
        var mod = Process.findModuleByName(modName);
        if (!mod) return;
        
        try {
            var exports = mod.enumerateExports();
            exports.forEach(function(exp) {
                if (exp.name.indexOf("xxtea_decrypt") >= 0 ||
                    exp.name.indexOf("xxtea_decode") >= 0 ||
                    exp.name.indexOf("getPackagekey") >= 0 ||
                    exp.name.indexOf("getKey") >= 0) {
                    
                    console.log("[+] Found XXTEA related: " + exp.name);
                    
                    Interceptor.attach(exp.address, {
                        onEnter: function(args) {
                            // 对于 getPackagekey / getKey 类型
                            // 返回值就是密钥
                            console.log("[XXTEA] " + exp.name + " called");
                            
                            // 输出参数
                            for (var i = 0; i < args.length; i++) {
                                try {
                                    var val = ptr(args[i]).readCString();
                                    if (val && val.length > 0 && val.length < 256) {
                                        console.log("  arg[" + i + "]: " + val);
                                    }
                                } catch(e) {}
                            }
                        },
                        onLeave: function(retval) {
                            try {
                                var key = ptr(retval).readCString();
                                if (key && key.length > 0 && key.length < 64) {
                                    console.log("[XXTEA KEY] " + key);
                                }
                            } catch(e) {
                                console.log("[XXTEA] retval: " + retval);
                            }
                        }
                    });
                }
            });
        } catch(e) {}
    });
}
```

### 4.4 使用 Python 解密

```python
# XXTEA 解密 Python 脚本
import xxtea
import struct

def decrypt_lua_xxtea(encrypted_path, key, output_path):
    with open(encrypted_path, 'rb') as f:
        encrypted_data = f.read()
    
    # XXTEA 解密
    decrypted_data = xxtea.decrypt(encrypted_data, key)
    
    # 检查解密结果是否有效 Lua 字节码
    if decrypted_data:
        # Lua 字节码前 4 个字节: "\x1bLua"
        if decrypted_data[:4] == b'\x1bLua':
            with open(output_path, 'wb') as f:
                f.write(decrypted_data)
            print(f"[+] Decrypted: {output_path}")
            
            # 可以使用 luadec 或 unluac 反编译
            # java -jar unluac.jar output.lua > output_source.lua
        else:
            print("[-] Decryption failed: invalid Lua bytecode magic")
    else:
        print("[-] Decryption failed")

# 使用示例
decrypt_lua_xxtea(
    "encrypted_script.luac", 
    "your_xxtea_key", 
    "decrypted_script.luac"
)
```

## 6. 常见问题与解决

### 6.1 luaL_loadbuffer 找不到

```javascript
// 问题：Module.findExportByName 找不到 luaL_loadbuffer
// 原因：引擎可能使用了 LuaJIT（使用 lua_load/luaL_loadbufferx）
// 或者函数被静态链接（无导出符号）

// 解决：尝试 Hook lua_load（Lua 5.1/5.2）或 luaL_loadbufferx（Lua 5.3+）
function findLuaLoadFunctions() {
    var candidates = [
        "luaL_loadbuffer",     // Lua 标准
        "luaL_loadbufferx",    // Lua 5.3+
        "lua_load",            // LuaJIT 或低版本
        "luaL_loadstring",     // 加载字符串
        "luaL_loadfile",       // 加载文件
    ];
    
    Process.enumerateModules().forEach(function(mod) {
        try {
            var exports = mod.enumerateExports();
            exports.forEach(function(exp) {
                candidates.forEach(function(c) {
                    if (exp.name.indexOf(c) >= 0) {
                        console.log("[+] " + exp.name + " in " + 
                                   mod.name + " @ " + exp.address);
                    }
                });
            });
        } catch(e) {}
    });
}
```

### 6.2 脚本被预编译为 luac 字节码

```javascript
// Lua 字节码文件以 \x1bLua 开头
// 如果 luaL_loadbuffer 的内容直接是 \x1bLua 开头
// 说明脚本是预编译的 .luac 文件（可能仍然有加密层）

// 验证脚本是否为 Lua 字节码
function isLuaBytecode(data) {
    if (data.length < 4) return false;
    // Lua 字节码魔数: \x1bLua (0x1b 0x4c 0x75 0x61)
    return data[0] === 0x1b && 
           data[1] === 0x4c && 
           data[2] === 0x75 && 
           data[3] === 0x61;
}
```

## 总结

- **核心 Hook 函数**：`luaL_loadbuffer` 是最关键的单点，所有 Lua 脚本最终都通过它加载
- **多策略组合**：同时 Hook `getFileData`、`fopen`、`luaL_loadbuffer`、`xxtea_decrypt` 提高完整度
- **XXTEA 加密**：Cocos2d-x 默认使用 XXTEA 加密，密钥可通过 Hook `getPackagekey` 或固定字符串搜索获取
- **数据流追踪**：从 `fopen` → `fread` → 解密函数 → `luaL_loadbuffer` 的完整链路监控
- **反编译**：使用 unluac / luadec 等工具将 Lua 字节码还原为源码
- **参考脚本**：`awesomeFrida/MT.js`（262行）提供了完整的 Cocos2d-x 游戏逆向参考框架
