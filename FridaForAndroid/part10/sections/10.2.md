# 10.2 FRIDA-DEXDump 脱壳

> 核心要点：FRIDA-DEXDump 是最流行的基于 Frida 的自动化 DEX 脱壳工具。它通过在内存中搜索 DEX 魔数特征，批量 dump 出加固壳解密后的所有 DEX 文件。

## 1. FRIDA-DEXDump 概述

FRIDA-DEXDump 是开源的 Frida 脱壳工具，利用 Frida 注入目标进程，自动扫描进程内存空间，搜索 DEX 文件魔数并提取完整的 DEX 文件。

**核心原理：**

```
目标进程内存空间
    ↓
FRIDA-DEXDump 注入 JavaScript 脚本
    ↓
遍历所有已加载模块的内存区域
    ↓
搜索 "dex\n035\0" / "dex\n037\0" / "dex\n038\0" 魔数
    ↓
对每个匹配位置：
  1. 读取 DEX Header 验证合法性
  2. 从 Header 获取 fileSize
  3. 完整读取并写入文件
    ↓
输出: 多个 DEX 文件（DEX_xxxxx.dex）
```

## 3. 脱壳原理深度分析

### 3.1 DEX 搜索核心逻辑

```javascript
// FRIDA-DEXDump 核心搜索逻辑（伪代码）
function searchDex() {
    // DEX 文件的魔数特征
    var magicBytes = [
        [0x64, 0x65, 0x78, 0x0A, 0x30, 0x33, 0x35, 0x00],  // "dex\n035\0"
        [0x64, 0x65, 0x78, 0x0A, 0x30, 0x33, 0x37, 0x00],  // "dex\n037\0"
        [0x64, 0x65, 0x78, 0x0A, 0x30, 0x33, 0x38, 0x00],  // "dex\n038\0"
        [0x64, 0x65, 0x78, 0x0A, 0x30, 0x33, 0x39, 0x00],  // "dex\n039\0"
    ];
    
    // 枚举所有加载的模块
    Process.enumerateModules().forEach(function(module) {
        // 跳过 mapped 文件（避免重复扫描文件系统映射）
        if (module.path.indexOf("/data/app/") >= 0) return;
        
        // 使用 Memory.scanSync 扫描魔数
        magicBytes.forEach(function(magic) {
            var pattern = magic.map(function(b) {
                return ("0" + b.toString(16)).substr(-2);
            }).join(" ");
            
            var results = Memory.scanSync(module.base, module.size, pattern);
            results.forEach(function(match) {
                dumpDex(match.address);
            });
        });
    });
}
```

### 3.2 DEX 验证与 Dump

```javascript
// 验证并 dump DEX
function dumpDex(address) {
    // 读取 DEX Header 字段
    var fileSize = address.add(0x20).readU32();      // DEX 文件大小
    var headerSize = address.add(0x70).readU32();     // Header 大小
    var classDefsSize = address.add(0x58).readU32();  // 类定义数量
    var classDefsOff = address.add(0x5C).readU32();   // 类定义偏移
    var dataOff = address.add(0x68).readU32();        // 数据段偏移
    var dataSize = address.add(0x6C).readU32();       // 数据段大小
    
    // 验证：
    // 1. headerSize 必须为 0x70
    // 2. classDefsSize > 0（有些空 DEX 没有类）
    // 3. 文件大小合理（通常 > 1KB）
    if (headerSize !== 0x70) return;
    if (fileSize < 1024) return;
    
    // 完整性验证
    if (classDefsSize > 0 && classDefsSize < 100000) {
        if (classDefsOff > 0x70 && classDefsOff < fileSize) {
            // 看起来是有效的 DEX，执行 dump
            var buffer = address.readByteArray(fileSize);
            var filename = "/data/local/tmp/DEX_" + address + "_" + fileSize + ".dex";
            var file = new File(filename, "wb");
            file.write(buffer);
            file.flush();
            file.close();
            console.log("[+] DEX dumped: " + filename);
        }
    }
}
```

### 3.3 脱壳关键时序问题

FRIDA-DEXDump 无法在所有时间点成功脱壳，原因在于：

1. **时机过早**：壳尚未完成 DEX 解密
2. **时机过晚**：DEX 已被 GC 回收或内存被复用
3. **内存保护**：部分加固壳设置了 `mprotect(PROT_NONE)` 保护

**解决方案：**

```bash
# 方案一：spawn 模式 + hook dlopen 后延迟扫描
frida-dexdump -U -f com.example.app --spawn --delay 5000

# 方案二：重复扫描模式
frida-dexdump -U com.example.app --loop

# 方案三：hook 特定函数后触发 dump
# 在 dlopen 的 onLeave 中重新触发 FRIDA-DEXDump 扫描
```

## 4. FRIDA-DEXDump 的局限性

| 问题 | 说明 | 解决思路 |
|------|------|----------|
| **内存保护** | 壳使用 mprotect 设置不可读 | 先修改内存保护属性 |
| **分段加密** | DEX 分多段解密 | 配合 ClassLoader Hook |
| **VMP 保护** | 方法被抽离到 Native | 需结合 dex2oat 或手动修复 |
| **多 DEX** | 应用有多个 DEX | FRIDA-DEXDump 默认扫描所有 |
| **DEX 魔数篡改** | 部分壳修改魔数逃避扫描 | 搜索 ClassDef 或 code_item 特征 |

### 4.1 针对魔数被篡改的增强搜索

```javascript
// 当魔数被篡改时的备选搜索方案
function searchDexByClassDef() {
    // ClassDef 数组起始特征：classIdx (u4) + accessFlags (u4) 的模式
    // 通常 accessFlags 的值在 1-0x20000 范围内
    
    Process.enumerateModules().forEach(function(module) {
        var results = Memory.scanSync(module.base, module.size, 
            "?? ?? ?? ?? ?? ?? ?? ?? ?? ?? ?? ?? ?? ?? ?? ??");
        
        results.forEach(function(match) {
            // 尝试以 0x70 偏移为起始解析 DEX
            for (var offset = 0; offset < 0x100; offset += 4) {
                var candidate = match.address.sub(offset);
                try {
                    var magic = candidate.readCString(8);
                    // 检查魔数是否接近 DEX 魔数
                    if (magic.indexOf("dex") >= 0) {
                        dumpDex(candidate);
                        break;
                    }
                } catch(e) {}
            }
        });
    });
}
```

## 6. 结合 dlopen 的延迟脱壳

```javascript
// 引用：awesomeFrida/dump-so.js（51行）的 dlopen 拦截模式
// 在目标 DEX 加载后才触发 DEX 扫描，避免"时机过早"问题

function delayedDexDump() {
    var dlopenAddr = Module.findExportByName(null, "dlopen");
    var androidDlopenExt = Module.findExportByName(null, "android_dlopen_ext");
    
    function onDlopen(path) {
        if (path.indexOf("libjiagu") >= 0 ||    // 360 加固
            path.indexOf("libsec") >= 0 ||       // 腾讯加固
            path.indexOf("libNSafer") >= 0) {    // 网易加固
            // 等待壳初始化完成
            setTimeout(function() {
                triggerDexDump();
            }, 5000);
        }
    }
    
    // Hook dlopen
    if (dlopenAddr) {
        Interceptor.attach(dlopenAddr, {
            onEnter: function(args) {
                this.path = args[0].readCString();
            },
            onLeave: function(retval) {
                if (this.path && retval) {
                    onDlopen(this.path);
                }
            }
        });
    }
}

function triggerDexDump() {
    // 执行 FRIDA-DEXDump 的核心扫描逻辑
    var magic = "64 65 78 0A 30 33 35 00";
    Process.enumerateModules().forEach(function(m) {
        var results = Memory.scanSync(m.base, m.size, magic);
        results.forEach(function(r) {
            var size = ptr(r.address).add(0x20).readU32();
            if (size > 4096) {
                var buffer = ptr(r.address).readByteArray(size);
                var f = new File("/data/local/tmp/dex_" + r.address + ".dex", "wb");
                f.write(buffer);
                f.flush();
                f.close();
                console.log("[*] Dumped DEX at " + r.address + " size: " + size);
            }
        });
    });
}
```

## 总结

- **FRIDA-DEXDump** 是最主流的 Frida DEX 脱壳工具，通过内存魔数扫描实现自动化脱壳
- **核心原理**：搜索 `dex\n035\0` / `dex\n037\0` / `dex\n038\0` / `dex\n039\0` 魔数特征
- **关键参数**：`--deep-search`（深度扫描）、`--spawn`（启动模式）、`--loop`（循环扫描）
- **局限**：对魔数篡改、分段加密、VMP 保护等方案无效，需要辅助其他手段
- **结合 dlopen Hook** 可以解决脱壳时机问题，在壳初始化完成后触发扫描
- 如果 FRIDA-DEXDump 失败，请转到 10.3 节使用 Frida 脚本手动 dump
