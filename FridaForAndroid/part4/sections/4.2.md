# 4.2 Java.choose 枚举实例调用

> 当需要调用的方法是**实例方法（非静态）**时，必须先获取目标类的对象实例。`Java.choose()` 是 Frida 提供的**堆上枚举**机制，可以在 Dalvik / ART 堆上遍历所有指定类的已加载实例。

## 1. Java.choose 原理

```javascript
Java.choose(className, {
    onMatch: function(instance) {
        // 处理每一个匹配的实例
    },
    onComplete: function() {
        // 枚举结束后的回调
    }
})
```

`Java.choose` 会在 Dalvik/ART 堆中搜索所有类型匹配的实例，对每个实例调用 `onMatch` 回调。这是一个**同步操作**，枚举期间会停止 App 线程。

> **引用**：`AndroidFridaBeginnersBook-main/Chap04/call.js` 第 2-9 行展示了静态方法调用；`Java.choose` 用于获取实例后调用其实例方法。

## 2. 基础示例：获取 Activity 实例

Activity 是 Android 中最常见的实例化类，获取当前 Activity 实例可以调用其方法：

```javascript
function callActivityMethod() {
    Java.perform(function() {
        Java.choose('com.example.junior.MainActivity', {
            onMatch: function(instance) {
                console.log("找到 MainActivity 实例:", instance)
                console.log("toString:", instance.toString())

                // 调用实例方法
                var title = instance.getTitle()
                console.log("Activity 标题:", title)

                // 修改实例字段
                instance.mSomeField.value = "新值"
            },
            onComplete: function() {
                console.log("MainActivity 枚举完毕")
            }
        })
    })
}
```

## 3. 访问实例字段

`Java.choose` 获取实例后，可以通过 `.字段名.value` 读写实例字段：

```javascript
Java.choose('com.roysue.network.HttpManager', {
    onMatch: function(instance) {
        // 读取私有字段（即使是 private 也可以访问）
        var baseUrl = instance.mBaseUrl.value
        console.log("Base URL:", baseUrl)

        // 修改字段值
        instance.mTimeout.value = 30000
        console.log("已修改超时时间为 30s")
    },
    onComplete: function() {}
})
```

## 4. Hook 已有的实例方法

`Java.choose` 配合 `implementation` 可以**覆盖已有实例的方法实现**：

```javascript
Java.choose('okhttp3.OkHttpClient', {
    onMatch: function(client) {
        // 修改 OkHttpClient 的 connectTimeout
        var builder = client.newBuilder()
        builder.connectTimeout(5000, Java.use('java.util.concurrent.TimeUnit').MILLISECONDS)
        var newClient = builder.build()
        console.log("已修改 OkHttpClient 连接超时")
    },
    onComplete: function() {}
})
```

## 5. 遍历多个实例

`Java.choose` 可能找到同一个类的多个实例。例如在 ListView 中遍历多个 ViewHolder：

```javascript
Java.choose('com.roysue.adapter.ViewHolder', {
    onMatch: function(instance, index) {
        console.log("ViewHolder #" + index + ":")
        console.log("  title:", instance.mTitle.value)
        console.log("  content:", instance.mContent.value)

        // 修改内容
        instance.mContent.value = "Frida 注入内容"
    },
    onComplete: function() {
        console.log("共遍历完所有 ViewHolder 实例")
    }
})
```

`onMatch` 回调的第二个参数是当前匹配的索引（从 0 开始）。

## 6. 获取 Android 系统服务的实例

```javascript
// 获取 TelephonyManager 实例
Java.choose('android.telephony.TelephonyManager', {
    onMatch: function(tm) {
        console.log("Device ID:", tm.getDeviceId())
        console.log("Network Operator:", tm.getNetworkOperatorName())
    },
    onComplete: function() {}
})

// 获取 WifiManager 实例
Java.choose('android.net.wifi.WifiManager', {
    onMatch: function(wm) {
        var wifiInfo = wm.getConnectionInfo()
        console.log("SSID:", wifiInfo.getSSID())
        console.log("BSSID:", wifiInfo.getBSSID())
    },
    onComplete: function() {}
})
```

## 7. Java.choose vs Java.use 对比

| 特性 | `Java.use()` | `Java.choose()` |
|:---:|:---:|:---:|
| 调用场景 | **静态方法** | **实例方法** |
| 是否需要实例 | ❌ 不需要 | ✅ 必须 |
| 性能开销 | 低（类级别） | 高（堆遍历） |
| 适用方法 | `static` 方法 | 非 `static` 方法 |
| 字段修改 | 仅静态字段 | 实例字段 + 静态字段 |
| 使用复杂度 | 简单 | 中等 |

## 8. 完整实战：遍历并调用所有 Fragment

```javascript
function enumerateFragments() {
    Java.perform(function() {
        var Fragment = Java.use('android.app.Fragment')
        var FragmentManager = Java.use('android.app.FragmentManager')

        Java.choose('android.app.Fragment', {
            onMatch: function(fragment) {
                console.log("Fragment 类名:", fragment.getClass().getName())
                console.log("  ID:", fragment.getId())
                console.log("  Tag:", fragment.getTag())
                console.log("  View:", fragment.getView())

                // 如果用户可见
                if (fragment.getUserVisibleHint()) {
                    console.log("  用户可见: true")
                }
            },
            onComplete: function() {
                console.log("Fragment 枚举完成")
            }
        })
    })
}
```

## 9. 注意事项

| 问题 | 解决方案 |
|:---|:---|
| **性能影响** | `Java.choose` 遍历堆时 App 线程暂停，尽量在 `onComplete` 后操作 |
| **找不到实例** | 确保类已加载（先调用 `Java.use`），或等待一段时间 |
| **多实例干扰** | 通过 `instance.getClass().getName()` 确认实例类型 |
| **实例已释放** | `Java.choose` 实例是弱引用，长时间持有可能失效 |
| **null 检查** | 始终对 `instance` 做 null 检查 |

## 10. 运行命令

```bash
# 以 Attach 模式注入，适合对已运行的 App 操作 Activity 等实例
frida -U com.example.junior -l call_instance.js

# 或使用 Spawn 模式，但需等待 Activity 创建完成
frida -U -f com.example.junior -l call_instance.js --no-pause
sleep 2  # 等待 Activity 创建
```
