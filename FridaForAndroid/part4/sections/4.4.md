# 4.4 Python 端调用 RPC

> RPC 的真正威力在于**跨语言调用**。本节讲解如何通过 Frida 的 Python 绑定，利用 `script.exports` 远程调用 JS 端导出的函数。

## 1. Python 端基础框架

```python
import frida, sys

def on_message(message, data):
    if message['type'] == 'send':
        print("[*] {0}".format(message['payload']))
    else:
        print(message)

# 连接设备
device = frida.get_usb_device()
# 或远程连接
# device = frida.get_device_manager().add_remote_device('192.168.50.129:1234')

process = device.attach('com.example.junior')

with open('call.js') as f:
    jscode = f.read()

script = process.create_script(jscode)
script.on('message', on_message)
script.load()

# 调用 RPC 导出函数
for i in range(20, 30):
    for j in range(0, 10):
        script.exports.sub(str(i), str(j))
```

## 3. script.exports 使用详解

`script.load()` 之后，`script.exports` 对象会包含所有 JS 端 `rpc.exports` 导出的方法。

### 3.1 基本调用

```python
# JS 端导出: rpc.exports = { add: function(a, b) { return a + b } }
result = script.exports.add(1, 2)
print(result)  # 3
```

### 3.2 调用带 Java 对象的 RPC

```python
# JS 端导出函数内部会自动创建 Java 对象
result = script.exports.sub("123", "111")
print("减法结果:", result)
```

### 3.3 异步 RPC 调用

```python
# 默认是同步调用，会等待 JS 端执行完成
import time

start = time.time()
result = script.exports.heavyComputation(1000000)
elapsed = time.time() - start
print(f"结果: {result}, 耗时: {elapsed:.2f}s")
```

## 4. 多参数与复杂类型

```python
# 字符串参数
script.exports.setName("admin")

# 数值参数
script.exports.setTimeout(5000)

# 布尔参数
script.exports.setEnabled(True)

# 数组参数
script.exports.processList(["item1", "item2", "item3"])

```

## 5. 消息回调与 RPC 配合

RPC 主要用于**主动调用**，`send()` 用于**日志通知**。两者可以配合使用：

```python
def on_message(message, data):
    if message['type'] == 'send':
        payload = message['payload']
        if isinstance(payload, dict) and 'type' in payload:
            if payload['type'] == 'log':
                print("[LOG]", payload['content'])
            elif payload['type'] == 'error':
                print("[ERROR]", payload['content'])
        else:
            print("[*]", payload)
    elif message['type'] == 'error':
        print("[SCRIPT ERROR]", message)
```

对应 JS 端：

```javascript
rpc.exports = {
    login: function(username, password) {
        Java.perform(function() {
            try {
                var LoginMgr = Java.use('com.roysue.LoginManager')
                var result = LoginMgr.login(username, password)
                send({type: 'log', content: '登录成功: ' + username})
                return result
            } catch (e) {
                send({type: 'error', content: e.message})
                return null
            }
        })
    }
}
```

## 7. 完整的 Python 控制脚本

```python
#!/usr/bin/env python3
# 文件名: loader_full.py
# 引用: AndroidFridaBeginnersBook-main/Chap04/loader.py
import frida
import sys
import json

class FridaRPCClient:
    def __init__(self, package_name, script_path, device_id=None):
        self.package_name = package_name
        self.script_path = script_path

        # 连接设备
        if device_id:
            self.device = frida.get_device(device_id)
        else:
            self.device = frida.get_usb_device()

        # Attach 到进程
        self.session = self.device.attach(package_name)

        # 加载脚本
        with open(script_path) as f:
            self.jscode = f.read()
        self.script = self.session.create_script(self.jscode)
        self.script.on('message', self.on_message)
        self.script.load()
        print(f"[+] 已连接到 {package_name}")

    def on_message(self, message, data):
        if message['type'] == 'send':
            print("[*]", message['payload'])
        elif message['type'] == 'error':
            print("[!]", message)

    def call(self, method, *args):
        """调用 RPC 方法"""
        return getattr(self.script.exports, method)(*args)

    def close(self):
        self.session.detach()

# 使用示例
if __name__ == '__main__':
    client = FridaRPCClient(
        package_name='com.example.junior',
        script_path='call.js'
    )

    # 批量调用
    for i in range(20, 30):
        for j in range(10):
            result = client.call('sub', str(i), str(j))
            print(f"sub({i}, {j}) = {result}")

    client.close()
```

## 9. 常见问题

| 问题 | 原因 | 解决方案 |
|:---|:---|:---|
| `script.exports.sub is not a function` | 脚本未加载完成 | 确保 `script.load()` 已调用 |
| 调用超时 | `Java.perform` 阻塞 | 减少耗时操作，使用异步模式 |
| 参数类型错误 | Python int 与 Java int 不兼容 | JS 端做类型转换 |
| 返回值 None | RPC 内 `Java.perform` 异步 | 正确使用闭包捕获变量 |
| `get_usb_device()` 失败 | USB 连接未授权 | 检查 `frida-server` 运行状态 |
