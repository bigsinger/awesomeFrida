# 4.5 内部类 Hook 与调用

> Java 内部类在 Android ART 虚拟机中以 `OuterClass$InnerClass` 的形式存在。Hook 内部类和调用内部类方法时需要特殊的语法处理。

## 1. 内部类的命名规则

在 ART 虚拟机中，内部类的类名格式为：

```
包名.外部类$内部类
```

### 常见类型

| 内部类类型 | 类名示例 |
|:---:|:---|
| 成员内部类 | `com.roysue.Outer$Inner` |
| 静态内部类 | `com.roysue.Outer$StaticInner` |
| 匿名内部类 | `com.roysue.Outer$1` |
| 匿名内部类嵌套 | `com.roysue.Outer$1$1` |
| 局部内部类 | `com.roysue.Outer$1Local` |
| OkHttp Builder | `okhttp3.OkHttpClient$Builder` |

### 快速定位已加载的内部类

```javascript
Java.enumerateLoadedClasses({
    onMatch: function(className) {
        if (className.indexOf('$') !== -1) {
            console.log("内部类:", className)
        }
    },
    onComplete: function() {
        console.log("枚举完毕")
    }
})
```

## 2. Frida 中使用 $ 符号

Frida 中 `$` 是保留符号。`Java.use` 内部能够正确处理包含 `$` 的类名：

```javascript
// OkHttpClient 的内部类 Builder
var Builder = Java.use('okhttp3.OkHttpClient$Builder')
console.log(Builder)  // <class: okhttp3.OkHttpClient$Builder>

// 访问 Builder 的方法
Builder.build.implementation = function() {
    console.log("Builder.build 被调用")
    return this.build()
}
```

## 3. Hook 匿名内部类

匿名内部类以 `OuterClass$N` 形式命名（N 为数字）：

### 3.1 Hook onClickListener

```javascript
// 匿名内部类：com.roysue.MainActivity$1 实现了 View.OnClickListener
Java.perform(function() {
    var AnonymousClass = Java.use('com.roysue.MainActivity$1')

    AnonymousClass.onClick.implementation = function(view) {
        console.log("onClick 被调用, view:", view)
        // 调用原始实现
        return this.onClick(view)
    }
})
```

### 3.2 查找所有匿名内部类

```javascript
Java.perform(function() {
    Java.enumerateLoadedClasses({
        onMatch: function(className) {
            // 匹配匿名内部类模式：数字结尾的 $ 类
            if (className.match(/\$\d+$/)) {
                console.log("匿名内部类:", className)
            }
        },
        onComplete: function() {}
    })
})
```

## 4. Hook 内部类的构造函数

```javascript
// 内部类构造函数 Hook
Java.perform(function() {
    var InnerClass = Java.use('com.roysue.OuterClass$InnerClass')

    InnerClass.$init.implementation = function() {
        console.log("InnerClass 构造函数被调用")
        console.log("堆栈:", Java.use("android.util.Log")
            .getStackTraceString(Java.use("java.lang.Throwable").$new()))
        return this.$init()
    }
})
```

## 5. 访问外部类引用

内部类通常持有外部类的引用（名为 `this$0`），可以通过 Frida 访问：

```javascript
Java.perform(function() {
    Java.choose('com.roysue.OuterClass$InnerClass', {
        onMatch: function(inner) {
            // 访问外部类引用（字段名通常是 this$0 或 outer$0）
            var outer = inner.this$0.value
            console.log("内部类实例:", inner)
            console.log("外部类引用:", outer)
            console.log("外部类字段:", outer.mSomeField.value)
        },
        onComplete: function() {}
    })
})
```

## 6. 创建内部类实例

### 6.1 静态内部类

静态内部类不持有外部类引用，可以直接实例化：

```javascript
Java.perform(function() {
    var StaticInner = Java.use('com.roysue.OuterClass$StaticInner')
    var instance = StaticInner.$new()
    console.log("静态内部类实例:", instance)
})
```

### 6.2 成员内部类

成员内部类需要外部类实例来创建：

```javascript
Java.perform(function() {
    var OuterClass = Java.use('com.roysue.OuterClass')
    var InnerClass = Java.use('com.roysue.OuterClass$InnerClass')

    // 获取或创建外部类实例
    Java.choose('com.roysue.OuterClass', {
        onMatch: function(outer) {
            // 通过外部类实例创建内部类
            var inner = InnerClass.$new(outer)
            console.log("成员内部类实例:", inner)
            inner.someMethod()
        },
        onComplete: function() {}
    })
})
```

## 7. 处理混淆后的内部类

当 App 经过混淆后，内部类名可能是 `a$a`、`b$c` 等，需要使用 `Java.enumerateLoadedClasses` 找出：

```javascript
function findObfuscatedInnerClass(outerClassPattern) {
    Java.perform(function() {
        Java.enumerateLoadedClasses({
            onMatch: function(className) {
                // 匹配混淆后的内部类模式
                if (className.match(/\.[a-z]\$\w+/)) {
                    console.log("疑似混淆内部类:", className)

                    // 尝试加载并打印方法列表
                    try {
                        var clz = Java.use(className)
                        console.log("  方法列表:", Object.getOwnPropertyNames(clz))
                    } catch(e) {
                        console.log("  加载失败:", e)
                    }
                }
            },
            onComplete: function() {}
        })
    })
}
```

## 8. 内部类 Hook 综合示例

```javascript
// hook_inner_class.js
Java.perform(function() {
    // 1. OkHttpClient$Builder（静态内部类）
    var Builder = Java.use('okhttp3.OkHttpClient$Builder')
    Builder.build.implementation = function() {
        console.log("[Builder.build] 拦截到 OkHttpClient 构建")
        return this.build()
    }

    // 2. Activity 匿名内部类（OnClickListener）
    Java.enumerateLoadedClasses({
        onMatch: function(className) {
            if (className.indexOf('MainActivity$') !== -1) {
                try {
                    var clz = Java.use(className)
                    if (clz.onClick) {
                        clz.onClick.implementation = function(view) {
                            console.log("[" + className + ".onClick] 点击事件")
                            return this.onClick(view)
                        }
                    }
                    if (clz.onLongClick) {
                        clz.onLongClick.implementation = function(view) {
                            console.log("[" + className + ".onLongClick] 长按事件")
                            return true
                        }
                    }
                } catch(e) {
                    console.error("Hook 失败:", e)
                }
            }
        },
        onComplete: function() {
            console.log("内部类扫描完毕")
        }
    })

    // 3. 枚举所有加载的 Builder 相关内部类
    Java.enumerateLoadedClasses({
        onMatch: function(className) {
            if (className.indexOf('$Builder') !== -1) {
                console.log("Builder 内部类:", className)
            }
        },
        onComplete: function() {}
    })
})
```

## 9. 注意事项

| 问题 | 说明 | 解决方案 |
|:---|:---|:---|
| 类名混淆 | 混淆后 `$` 位置可能变化 | 使用 `enumerateLoadedClasses` 枚举 |
| 多层嵌套 | `Outer$Middle$Inner` | 完整写出全路径 |
| 匿名内部类编号 | 不同版本编号可能不同 | 先枚举确认编号 |
| 语法糖 | Kotlin 内部类可能使用 `$` 或 `$$` | 检查实际类名 |
| 性能 | 大量枚举影响 App 运行 | 限定搜索范围 |

## 10. 运行命令

```bash
# 加载内部类 Hook 脚本
frida -U -f com.roysue.targetapp -l hook_inner_class.js --no-pause
```

> **引用**：`okhttp3.OkHttpClient$Builder` 是 OkHttp 中最常用的静态内部类；`Chap04/call.js` 展示了 `Java.use` 和 `Java.choose` 的基本模式。
