# 4.3 RPC 导出机制：rpc.exports

> RPC（Remote Procedure Call）是 Frida 提供的一种**跨语言通信机制**。通过 `rpc.exports`，JS 脚本可以将函数导出为远程可调用接口，Python / Node.js 端可以像调用本地函数一样调用这些接口。

## 1. rpc.exports 基础语法

Frida 脚本通过全局对象 `rpc.exports` 导出函数：

```javascript
rpc.exports = {
    functionName: function(param1, param2) {
        // 实现代码
        return result
    }
}
```

> **引用**：`AndroidFridaBeginnersBook-main/Chap04/call.js` 第 11-21 行

## 2. 基础示例：导出算术运算

```javascript
// 引用：AndroidFridaBeginnersBook-main/Chap04/call.js 第 11-21 行
rpc.exports = {
    sub: function CallSub(a, b) {
        Java.perform(function() {
            var Arith = Java.use('com.example.junior.util.Arith')
            var JavaString = Java.use('java.lang.String')
            var result = Arith.sub(JavaString.$new(a), JavaString.$new(b))
            console.log(a, "-", b, "=", result)
            // 生产环境建议改为 send(a, "-", b, "=", result)
        })
    }
}
```

### 关键点解析

| 概念 | 说明 |
|:---|:---|
| `rpc.exports` | 全局对象，Frida 会自动将其属性暴露为远程接口 |
| **函数名 (key)** | Python 端通过 `script.exports.sub()` 调用 |
| **参数传递** | JS 基本类型直接传递，Java 对象需在内部创建 |
| **`Java.perform`** | RPC 导出的函数内部必须包裹 `Java.perform` |
| **返回值** | 支持自动序列化，复杂对象需手动处理 |

## 3. 生产级示例：r0capture

`awesomeFrida/r0capture.js` 是 r0ysue 开发的生产级 SSL 抓包工具，其 RPC 导出如下（第 5-12 行）：

```javascript
// 引用：awesomeFrida/r0capture.js 第 5-12 行
rpc.exports = {
    setssllib: function (name) {
        console.log("setSSLLib => " + name);
        libname = name;
        initializeGlobals();
        return;
    }
};
```

这个导出允许 Python 端**动态切换 SSL 库名称**，使脚本能适配不同版本的 libssl / libboringssl。

## 4. 支持多种导出风格的函数

### 4.1 匿名函数

```javascript
rpc.exports = {
    sub: function(a, b) {  // 匿名
        return a - b
    }
}
```

### 4.2 命名函数

```javascript
rpc.exports = {
    sub: function mySub(a, b) {  // 命名函数 mySub
        return a - b
    }
}
```

两种写法在功能上完全等价。

## 5. 导出多个函数

```javascript
rpc.exports = {
    // 加密类方法
    aesEncrypt: function(data, key) {
        // ... 实现
    },
    aesDecrypt: function(data, key) {
        // ... 实现
    },

    // 网络请求类
    getCookies: function(url) {
        // ... 实现
    },

    // 数据类
    decodeResponse: function(base64Data) {
        // ... 实现
    }
}
```

## 6. RPC 与 `send` 的对比

| 特性 | `rpc.exports` | `send()` |
|:---:|:---:|:---:|
| 通信方向 | **双向**（Python → JS → Python） | 单向（JS → Python） |
| 调用方式 | 函数调用（同步/异步） | 事件监听 |
| 返回值 | ✅ 支持 | ❌ 不支持 |
| 参数传递 | 自动序列化 | `on_message` 回调 |
| 适用场景 | 主动调用、远程执行 | 日志输出、实时通知 |
| 实现复杂度 | 低 | 中 |

## 7. 错误处理

RPC 导出函数中的异常会被传递回调用端：

```javascript
rpc.exports = {
    safeCall: function(className, methodName) {
        try {
            Java.perform(function() {
                var targetClass = Java.use(className)
                var result = targetClass[methodName]()
                return result  // 注意：Java.perform 是异步的，返回值在回调外部
            })
        } catch (e) {
            console.error("RPC 调用失败:", e)
            return { error: e.message }
        }
    }
}
```

> ⚠️ **重要**：由于 `Java.perform` 是异步的，在回调**内部不能直接 `return`**。正确的做法是使用 `send` 或在回调内完成所有逻辑。

正确的同步写法：

```javascript
rpc.exports = {
    callStaticMethod: function(a, b) {
        var result
        Java.perform(function() {
            var Arith = Java.use('com.example.junior.util.Arith')
            result = Arith.add(a, b)  // 修改变量
        })
        // Java.perform 结束后才能安全读取
        return result
    }
}
```

## 8. RPC 与 Java.choose 结合

```javascript
rpc.exports = {
    getActivityTitle: function() {
        var title = null
        Java.perform(function() {
            Java.choose('com.roysue.MainActivity', {
                onMatch: function(instance) {
                    title = instance.getTitle()
                },
                onComplete: function() {}
            })
        })
        return title
    }
}
```

## 9. 注意事项

| 注意点 | 说明 |
|:---|:---|
| **线程模型** | RPC 调用在当前 JS 线程处理，如需 Java 环境必须 `Java.perform` |
| **返回值序列化** | 简单类型（string/number/boolean/array）自动序列化，Java 对象需手动处理 |
| **并发调用** | 多个 Python 端同时调用时需注意竞态条件 |
| **超时** | Python 端调用可能因 `Java.perform` 阻塞导致超时 |
| **调试** | 在 RPC 函数内使用 `console.log` 输出到终端 |

## 10. 完整脚本模板

```javascript
// rpc_template.js
"use strict";

rpc.exports = {
    // 加解密
    encrypt: function(plaintext) {
        var result = null
        Java.perform(function() {
            var Crypto = Java.use('com.roysue.crypto.AESUtil')
            var JavaString = Java.use('java.lang.String')
            var Base64 = Java.use('android.util.Base64')

            var encrypted = Crypto.encrypt(
                JavaString.$new(plaintext).getBytes(),
                JavaString.$new("secret_key_16byte").getBytes()
            )
            result = Base64.encodeToString(encrypted, 0)
        })
        return result
    },

    // 状态查询
    isLoggedIn: function() {
        var loggedIn = false
        Java.perform(function() {
            Java.choose('com.roysue.LoginManager', {
                onMatch: function(inst) {
                    loggedIn = inst.isLoggedIn()
                },
                onComplete: function() {}
            })
        })
        return loggedIn
    }
}
```

> **引用**：`Chap04/call.js` 第 11-21 行定义了基础 RPC 导出；`awesomeFrida/r0capture.js` 第 5-12 行展示了生产级 RPC 导出。
