# 4.1 静态方法主动调用

> **主动调用**是 Frida 超越被动 Hook 的核心能力之一。本节讲解如何通过 `Java.use().methodName()` 直接调用 Java 类的静态方法，即使 App 本身从未调用过该函数。

## 1. 核心原理

Frida 的 `Java.use(className)` 返回一个 Wrapper 对象，通过它可以直接调用目标类的**静态方法**和**构造函数**。其本质上利用了 Frida 内部的 JNI 桥接机制：

```
Frida JS 脚本 → Java.perform → JNI Bridge → ART Runtime → 目标方法
```

> **引用**：`AndroidFridaBeginnersBook-main/Chap04/call.js` 第 2-9 行

## 2. 基础示例：调用工具类的静态方法

假设目标 App 中有一个工具类 `com.example.junior.util.Arith`，包含静态方法 `sub(String, String)`：

```javascript
// 文件引用：AndroidFridaBeginnersBook-main/Chap04/call.js 第 1-9 行
function callSub() {
    Java.perform(function() {
        var Arith = Java.use('com.example.junior.util.Arith')
        var JavaString = Java.use('java.lang.String')
        var result = Arith.sub(JavaString.$new("123"), JavaString.$new("111"))
        console.log("123 - 111 =", result)
    })
}
```

### 逐行解析

| 行号 | 代码 | 说明 |
|------|------|------|
| 2 | `Java.perform(function() { ... })` | 确保 Java 环境就绪 |
| 3 | `Java.use('com.example.junior.util.Arith')` | 获取目标类的 Frida Wrapper |
| 4 | `Java.use('java.lang.String')` | 获取 `java.lang.String` 的 Wrapper，用于创建 Java 字符串 |
| 5 | `JavaString.$new("123")` | 调用 String 构造函数创建 Java 字符串实例 |
| 5 | `Arith.sub(...)` | **主动调用** `Arith` 类的 `sub` 静态方法 |
| 6 | `console.log(...)` | 输出返回值 |

> **注意**：`$new()` 是 Frida 提供的关键语法，用于调用 Java 构造函数。在 Frida 脚本中，所有 Java 字符串都必须通过 `Java.use('java.lang.String').$new("xxx")` 创建，而非直接使用 JS 字符串。

## 3. 常见返回值类型处理

| Java 返回值类型 | Frida 脚本处理方式 | 示例 |
|:---:|:---:|:---:|
| 基本类型 (int, long, boolean) | 直接使用 | `var result = Arith.add(1, 2)` |
| String | 直接使用 `Java.use('java.lang.String')` | `JavaString.$new("text")` |
| 自定义对象 | 进一步调用其方法 | `result.someMethod()` |
| void | 无返回值 | 直接调用即可 |
| 数组 | `Java.array('type', [elems])` | `Java.array('byte', [0x41, 0x42])` |

## 4. 调用带复杂参数的方法

### 4.1 基本类型参数

```javascript
var MathUtil = Java.use('com.roysue.util.MathUtil')
var sum = MathUtil.addInt(10, 20)  // public static int addInt(int, int)
console.log("10 + 20 =", sum)
```

### 4.2 数组参数

```javascript
var Arrays = Java.use('java.util.Arrays')
var MyClass = Java.use('com.roysue.MyClass')

// 创建 Java byte 数组
var byteArray = Java.array('byte', [0x48, 0x65, 0x6C, 0x6C, 0x6F])
var result = MyClass.processBytes(byteArray)
```

### 4.3 对象参数

```javascript
var Intent = Java.use('android.content.Intent')
var Context = Java.use('android.content.Context')

// 创建 Intent 对象
var intent = Intent.$new()
intent.setAction("android.intent.action.VIEW")

var ActivityManager = Java.use('android.app.ActivityManager')
// 调用需要 Context 参数的方法
```

## 5. 重载方法处理

当目标方法存在多个重载时，必须使用 `overload()` 精确指定签名：

```javascript
var CryptoUtil = Java.use('com.roysue.util.CryptoUtil')

// 方法存在多个重载：encrypt(String) 和 encrypt(String, String)
CryptoUtil.encrypt.overload('java.lang.String').implementation = function(input) {
    // 被动 Hook
    return this.encrypt(input)
}

// 主动调用时，Frida 会自动匹配唯一签名
var result = CryptoUtil.encrypt("plaintext")
// 但如果存在歧义，需用 overload 明确
var result2 = CryptoUtil.encrypt.overload('java.lang.String', 'java.lang.String')("plaintext", "key")
```

> **最佳实践**：当重载方法签名不确定时，先通过 `overloads` 属性查看所有重载：
> ```javascript
> console.log(JSON.stringify(CryptoUtil.encrypt.overloads))
> ```

## 6. 调用静态工厂方法

```javascript
var BitmapFactory = Java.use('android.graphics.BitmapFactory')

// 主动调用 BitmapFactory.decodeFile
var Bitmap = Java.use('android.graphics.Bitmap')
var filePath = JavaString.$new("/sdcard/Download/test.png")
var bitmap = BitmapFactory.decodeFile(filePath)
console.log("Bitmap width:", bitmap.getWidth(), "height:", bitmap.getHeight())
```

## 7. 实战：主动调用加密函数验证逆向结果

```javascript
function callEncrypt() {
    Java.perform(function() {
        var JavaString = Java.use('java.lang.String')
        var Base64 = Java.use('android.util.Base64')

        // 假设逆向分析发现 App 使用 AES 加密
        var AESUtil = Java.use('com.roysue.aes.AESUtil')
        var plaintext = JavaString.$new("HelloFrida")
        var key = JavaString.$new("0123456789abcdef")

        // 主动调用加密方法，验证逆向结果
        var cipherBytes = AESUtil.encrypt(plaintext.getBytes(), key.getBytes())
        var cipherBase64 = Base64.encodeToString(cipherBytes, 0)
        console.log("加密结果:", cipherBase64)

        // 解密验证
        var decryptedBytes = AESUtil.decrypt(Base64.decode(cipherBase64, 0), key.getBytes())
        var decrypted = JavaString.$new(decryptedBytes)
        console.log("解密结果:", decrypted)
    })
}
```

## 8. 注意事项

| 注意点 | 说明 |
|:---|:---|
| **线程安全** | `Java.perform` 在 Java 主线程执行，耗时操作避免阻塞 |
| **对象生命周期** | `$new()` 创建的 Java 对象由 ART 管理，不会自动 GC |
| **空指针** | 确保目标类已加载（可通过 `Java.available` 判断） |
| **性能** | 每次 `Java.use` 都有一定开销，可缓存 Wrapper 对象 |
| **异常处理** | 使用 `try-catch` 包裹主动调用代码 |

## 9. 完整运行命令

```bash
# 使用 Spawn 模式注入（推荐）
frida -U -f com.example.junior -l call_static.js --no-pause

# 使用 Attach 模式（App 已运行）
frida -U com.example.junior -l call_static.js
```
