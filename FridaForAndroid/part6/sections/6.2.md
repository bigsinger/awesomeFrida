# 6.2 BoringSSL（Chromium 系）绕过

> **BoringSSL** 是 Google 对 OpenSSL 的 Fork，Chrome、Chromium、Android WebView 以及大量使用 Chromium 网络栈的 App 都使用 BoringSSL。BoringSSL 的证书校验方式与 OpenSSL 不同，需要专门的绕过方案。

## 1. BoringSSL vs OpenSSL

| 对比项 | OpenSSL | BoringSSL |
|:---:|:---:|:---:|
| 使用场景 | libssl.so（通用） | libboringssl.so / libsscronet.so |
| 证书校验入口 | SSL_CTX_set_verify | SSL_CTX_set_custom_verify |
| Hook 难度 | 中（标准 API） | 高（自定义校验回调） |
| 典型 App | 普通 Android App | 字节系、Chrome、WebView |

## 2. BoringSSL 绕过原理

BoringSSL 通过 `SSL_CTX_set_custom_verify` 设置自定义校验回调函数。绕过思路是：

```
SSL_CTX_set_custom_verify(ctx, mode, callback)
                                ↓
                         Interceptor.attach(callback)
                                ↓
                     onLeave: retval.replace(0x0)  ← 强制返回 ssl_verify_ok
```

## 3. 核心绕过脚本

```javascript
// 引用：awesomeFrida/byPassSSL.js 完整 59 行
// 过字节系的 App 的防抓包方案

// ARM64 上 mov w0, #0 的机器码
function patch(address) {
    Memory.protect(address, 4, 'rwx');
    Memory.writeByteArray(address, [0x00, 0x00, 0x80, 0x52]);
}

function onLoad(name, callback) {
    // android_dlopen_ext(const char* filename, int flag, const android_dlextinfo* extinfo)
    const android_dlopen_ext = Module.findExportByName(null, "android_dlopen_ext");
    if (android_dlopen_ext != null) {
        Interceptor.attach(android_dlopen_ext, {
            onEnter: function(args) {
                if (args[0].readCString().indexOf(name) !== -1) {
                    this.hook = true;
                }
            },
            onLeave: function(retval) {
                if (this.hook) callback();
            }
        });
    }
}

function main() {
    Java.perform(function() {
        const soName = 'libsscronet.so';
        onLoad(soName, () => {
            // SSL_CTX_set_custom_verify 原型：
            // void SSL_CTX_set_custom_verify(SSL_CTX *ctx, int mode,
            //     enum ssl_verify_result_t (*callback)(SSL *ssl, uint8_t *out_alert));
            let SSL_CTX_set_custom_verify = Module.getExportByName(
                soName, 'SSL_CTX_set_custom_verify');
            if (SSL_CTX_set_custom_verify != null) {
                Interceptor.attach(SSL_CTX_set_custom_verify, {
                    onEnter: function(args) {
                        // args[2] 是自定义校验回调函数指针
                        Interceptor.attach(args[2], {
                            onLeave: function(retval) {
                                // ssl_verify_result_t:
                                //   ssl_verify_ok     = 0
                                //   ssl_verify_invalid = 1
                                //   ssl_verify_retry  = 2
                                // 将返回值强制替换为 ssl_verify_ok
                                if (retval > 0x0) retval.replace(0x0);
                            }
                        });
                    }
                });
            }
        });
    });
}

setImmediate(main);
```

> **引用**：`awesomeFrida/byPassSSL.js` 第 1-59 行。核心逻辑在第 37-53 行。

## 4. 关键代码解析

### 4.1 onLoad 函数（第 8-24 行）

```javascript
function onLoad(name, callback) {
    // android_dlopen_ext 是 Android 用来加载 SO 文件的内核扩展函数
    const android_dlopen_ext = Module.findExportByName(null, "android_dlopen_ext");
    if (android_dlopen_ext != null) {
        Interceptor.attach(android_dlopen_ext, {
            onEnter: function(args) {
                // args[0] 是文件名，检查是否包含目标 SO 名
                if (args[0].readCString().indexOf(name) !== -1) {
                    this.hook = true;
                }
            },
            onLeave: function(retval) {
                // SO 加载完成后调用回调
                if (this.hook) callback();
            }
        });
    }
}
```

`onLoad` 函数监听 SO 文件的动态加载，在 SO 加载完成后执行回调。这解决了 Frida Spawn 时 SO 尚未加载的问题。

### 4.2 SSL_CTX_set_custom_verify 拦截（第 37-53 行）

```javascript
Interceptor.attach(SSL_CTX_set_custom_verify, {
    onEnter: function(args) {
        // args[2] = callback 函数指针
        // 直接 Hook 这个回调函数
        Interceptor.attach(args[2], {
            onLeave: function(retval) {
                // 将返回值 > 0 的（校验失败/重试）替换为 0（成功）
                if (retval > 0x0) retval.replace(0x0);
            }
        });
    }
});
```

### 4.3 patch 函数（第 1-5 行）

```javascript
// 当需要直接修改内存中的指令时使用
function patch(address) {
    Memory.protect(address, 4, 'rwx');              // 设为可读写执行
    Memory.writeByteArray(address, [0x00, 0x00, 0x80, 0x52]);  // ARM64: mov w0, #0
}
```

`0x00 0x00 0x80 0x52` 是 ARM64 上 `mov w0, #0` 的机器码，将返回值寄存器 w0 置为 0（ssl_verify_ok）。

