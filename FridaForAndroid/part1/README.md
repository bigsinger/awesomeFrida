## 为什么先搭建环境？

Frida 采用 **C/S（客户端-服务器）架构**：

1. **客户端**：你的 PC（运行 Python/JS 脚本）
2. **服务器**：Android 设备上的 `frida-server`
3. **通信**：通过 TCP（USB 转发或网络直连）

> **一句话总结**：没有正确的环境，任何 Hook 都无法执行。本篇的目标就是让你 `frida-ps` 命令能看到目标设备和进程。

## 学习建议

- 按照 1.1 → 1.5 的顺序逐一完成

- 遇到版本兼容问题先检查 `frida --version` 和 `frida-server` 版本是否一致
