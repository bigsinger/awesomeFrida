# 1.2 环境搭建：Root设备与模拟器

## 设备选择方案

Frida 需要 root 权限才能注入其他进程。以下是三种推荐方案：

| 方案 | 优点 | 缺点 | 推荐指数 |
|------|------|------|---------|
| **真机 Root** | 真实环境，性能最好 | 有保修/保修风险 | ⭐⭐⭐ |
| **PC 模拟器** | 方便快捷，随时重置 | 部分检测 | ⭐⭐⭐⭐⭐ |
| **云手机** | 远程调试 | 需要网络 | ⭐⭐⭐ |

## 方案一：PC 模拟器（推荐）

### 推荐模拟器

| 模拟器 | Root | 特点 |
|--------|------|------|
| **雷电模拟器 (LDPlayer)** | 自带 Root 开关 | 最稳定，性能好 |
| **夜神模拟器 (Nox)** | 自带 Root | 兼容性好 |
| **MuMu 模拟器** | 需自行 Root | 网易出品 |
| **Genymotion** | 自带 Root | 开发首选 |

### 雷电模拟器配置步骤

```bash
# 1. 开启 Root 权限
# 在模拟器设置中打开 "Root 权限"

# 2. 确认 adb 连接
adb devices
# 输出示例：
# List of devices attached
# emulator-5554   device

# 3. 进入 root shell 验证
adb shell
su
whoami
# 输出应为：root
```

> **注意**：模拟器可能不支持 `x86_64` 架构的 frida-server，建议使用 `x86` 版本。

## 方案二：真机 Root

### 常见 Root 方案

| 方案 | 适用场景 | 说明 |
|------|---------|------|
| **Magisk** | 主流 Android 9+ | 系统less Root，支持隐藏 |
| **SuperSU** | 旧设备 | 经典方案 |
| **TWRP + SuperSU** | 通用 | 需要解锁 Bootloader |

### Magisk 刷入流程

```bash
# 1. 解锁 Bootloader（不同品牌方法不同）
fastboot oem unlock      # 通用命令
fastboot flashing unlock # 部分设备

# 2. 刷入 TWRP Recovery
fastboot flash recovery twrp-3.3.0-0-bullhead.img

# 3. 通过 TWRP 刷入 Magisk
# 将 Magisk-v20.4.zip 推送到设备后，在 TWRP 中 Install
adb push Magisk-v20.4.zip /sdcard/
```

> 以上 Magisk 和 TWRP 文件引用自 `Chap01/` 目录：
> - `Chap01/Magisk-v20.4.zip`
> - `Chap01/SR5-SuperSU-v2.82-SR5-20171001224502.zip`
> - `Chap01/twrp-3.3.0-0-bullhead.img`

## 验证 Root 是否成功

```bash
adb shell
su
# 如果 $ 变为 # 表示已成功
id
# 输出示例：uid=0(root) gid=0(root) groups=0(root)
```

## adb 工具安装

```bash
# Windows - 下载 Platform Tools
# https://developer.android.com/studio/releases/platform-tools

# macOS
brew install android-platform-tools

# Ubuntu/Debian
sudo apt install adb fastboot

# 验证安装
adb --version
# Android Debug Bridge version 1.0.41
```

## 常见问题

### Q1: adb 找不到设备
```bash
# 检查 USB 调试是否开启
adb kill-server
adb start-server
adb devices
```

### Q2: 模拟器 root 失败
```bash
# 雷电模拟器手动开启 root
# 模拟器右上角菜单 → 设置 → 其他设置 → Root 权限 → 开启
# 需要重启模拟器生效
```

### Q3: su: not found
- 真机：需要重新刷入 Root 包
- 模拟器：检查 Root 开关是否开启

## 小结

- **优先推荐雷电模拟器**——自带 Root、方便管理、性能好
- 真机推荐 Magisk 方案
- 验证 Root：`adb shell` → `su` → `id` 显示 uid=0
- 不同架构选择对应版本的 frida-server（下节详述）
