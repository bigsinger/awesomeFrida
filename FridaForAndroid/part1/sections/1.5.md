# 1.5 Frida CLI 工具集详解

Frida 提供了一系列命令行工具，构成完整的逆向工作流。这些工具随 `frida-tools` 一起安装。

## 工具总览

| 命令 | 用途 | 地位 |
|------|------|------|
| `frida` | 交互式脚本注入 | ⭐⭐⭐⭐⭐ |
| `frida-ps` | 进程列表查看 | ⭐⭐⭐⭐⭐ |
| `frida-trace` | 自动追踪函数调用 | ⭐⭐⭐⭐ |
| `frida-ls-devices` | 设备列表 | ⭐⭐⭐⭐ |
| `frida-discover` | 内部调用发现 | ⭐⭐⭐ |
| `frida-kill` | 进程终止 | ⭐⭐⭐ |
| `frida-apk` | APK 操作（已弃用） | ⭐⭐ |

## 1. frida-ps：进程列表

最常用的命令，用于查看目标设备上的进程信息。

```bash
# 查看 USB 设备上的所有进程
frida-ps -U

# 查看进程 PID 和名称
frida-ps -Ua

# 只显示设备名称
frida-ps -U -i com.example

# 按名称过滤（只显示包含特定关键词的进程）
frida-ps -U | grep chrome

# 查看网络连接设备上的进程
frida-ps -R 192.168.50.129:1234
```

**输出示例：**
```
  PID  Name
-----  --------------------
 1234  com.android.systemui
 5678  com.example.app
 9012  com.android.chrome
```

## 2. frida-ls-devices：查看设备

列出所有可用的 Frida 设备（USB、本地、网络）。

```bash
# 列出所有设备
frida-ls-devices

# 输出示例：
# Id                    Type    Name
# ----------------------------------------
# local                 local   Local System
# emulator-5554         usb     Android Emulator
# 192.168.50.129:1234   remote  Remote Device
```

**常见设备类型：**
| 类型 | 标识 | 说明 |
|------|------|------|
| `local` | 本机 | 在 PC 上直接运行 |
| `usb` | USB 连接 | 连接的真实设备或模拟器 |
| `remote` | 网络连接 | 通过 `-R` 或 `add_remote_device` 连接 |

## 3. frida：交互式注入

最强大的工具，可实时注入脚本并与目标进程交互。

```bash
# 基本用法
frida -U com.example.app         # Attach 到已运行的进程
frida -U -f com.example.app      # Spawn（启动新进程）
frida -U -f com.example.app -l script.js  # Spawn 并加载脚本

# 常用选项
frida -U -n chrome               # 按进程名匹配
frida -U -p 1234                 # 按 PID 匹配
frida -U -f com.example.app --no-pause  # Spawn 后不暂停

# REPL 模式（交互式）
frida -U com.example.app
# 进入交互界面后可直接输入 JS 代码
# Java.perform(function(){ console.log("inline hook!"); })
```

## 4. frida-trace：自动追踪

自动为指定函数生成 Hook 脚本，非常适合快速分析。

```bash
# 追踪 Java 方法
frida-trace -U com.example.app -j 'com.example.util.*!*'

# 追踪 native 函数（导出表）
frida-trace -U com.example.app -i 'strcmp'

# 追踪 libc 中的函数
frida-trace -U com.example.app -i 'libc.so!*'

# 生成追踪脚本到指定目录
frida-trace -U com.example.app -j '*!*' -O ./traces/

# 结合过滤
frida-trace -U com.example.app -j 'com.example.*!*' -m 'main|onClick'
```

**选项说明：**

| 选项 | 含义 | 示例 |
|------|------|------|
| `-j` | Java 方法 | `-j 'com.example.*!*'` |
| `-i` | Native 导出函数 | `-i 'strcmp'` |
| `-I` | Native 包含模块 | `-I 'libc.so'` |
| `-x` | 排除模块 | `-x 'libc.so'` |
| `-m` | 包含模块 | `-m 'libm.so'` |

## 5. frida-discover：调用发现

自动发现进程内部的方法调用关系。

```bash
# 发现 Java 方法
frida-discover -U com.example.app

# 输出示例：
# [*] Resolving Java classes...
# [*] Found 42 classes
# [*] Analyzing method calls...
# com.example.util.Arith.sub(String, String)
# com.example.util.Arith.add(String, String)
```

## 6. frida-kill：终止进程

杀死目标进程（需要匹配完整的进程名）。

```bash
# 终止进程
frida-kill -U com.example.app

# 终止 PID
frida-kill -U 1234
```

## 实战组合命令

### 典型分析流程

```bash
# 1. 查看设备和进程
frida-ls-devices
frida-ps -U

# 2. 追踪所有 Java 方法调用
frida-trace -U com.example.app -j '*!*'

# 3. 针对性 hook 特定类
frida-trace -U com.example.app -j 'com.example.util.*!*'

# 4. 交互式注入调试
frida -U com.example.app -l hook.js

# 5. 使用 Python 客户端自动化
python loader.py
```

### 批量追踪脚本生成

```bash
# 为包下所有类的所有方法生成追踪脚本
frida-trace -U com.example.app -j 'com.example.*!*'

# 生成的脚本保存在 __handlers__/ 目录
ls __handlers__/
# com.example.util.Arith/sub.js
# com.example.util.Arith/add.js
```

## 小结

| 工具 | 核心用途 | 常用选项 |
|------|---------|---------|
| `frida-ps` | 列出进程 | `-U`, `-R`, `-i` |
| `frida-ls-devices` | 列出设备 | 无参数 |
| `frida` | 交互注入 | `-U`, `-f`, `-l`, `-p` |
| `frida-trace` | 自动追踪 | `-j`, `-i`, `-x` |
| `frida-discover` | 调用发现 | `-U` |
| `frida-kill` | 杀进程 | `-U` |

> **学习建议**：优先熟练掌握 `frida-ps`、`frida` 和 `frida-trace` 三个工具，覆盖日常逆向需求的 90%。
