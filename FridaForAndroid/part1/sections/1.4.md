# 1.4 Python + Node.js 开发环境配置

## Python 环境

### 安装 Python 3

```bash
# Windows
# 从 https://www.python.org/downloads/ 下载安装包
# 安装时勾选 "Add Python to PATH"

# macOS
brew install python3

# Ubuntu/Debian
sudo apt install python3 python3-pip python3-venv

# 验证
python3 --version
# Python 3.10.x
pip3 --version
```

### 安装 frida 与 frida-tools

```bash
# 核心安装
pip3 install frida frida-tools

# 验证安装
frida --version
# 14.1.3
frida-tools --version
# 9.2.0
frida-ps --version
```

### 虚拟环境（推荐）

```bash
# 创建虚拟环境
python3 -m venv frida_env

# 激活
# Linux/macOS
source frida_env/bin/activate

# Windows
frida_env\Scripts\activate

# 在虚拟环境中安装
pip install frida frida-tools

# 退出虚拟环境
deactivate
```

### Python 绑定基础结构

以下是最基本的 Frida Python 客户端脚本，展示了从连接设备到加载脚本的完整流程：

```python
# 引用自 Chap04/loader.py 第 1-20 行（精简核心结构）
import frida, sys

def on_message(message, data):
    if message['type'] == 'send':
        print("[*] {0}".format(message['payload']))
    else:
        print(message)

# 连接设备
device = frida.get_usb_device()
# 或使用网络连接
# device = frida.get_device_manager().add_remote_device('192.168.50.129:1234')

# 附加到目标进程
process = device.attach('com.example.junior')

# 加载 JavaScript 脚本
with open('call.js') as f:
    jscode = f.read()
script = process.create_script(jscode)

# 注册消息回调
script.on('message', on_message)

# 加载脚本
script.load()

# 保持进程运行
sys.stdin.read()
```

> **代码来源**：`Chap04/loader.py` 第 1-20 行，展示了 frida Python 绑定的标准流程。

## Node.js 环境

### 安装 Node.js

```bash
# 推荐使用 nvm（Node Version Manager）
# Linux/macOS
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# 安装 Node.js LTS
nvm install --lts
nvm use --lts

# Windows - 从 https://nodejs.org/ 下载安装包

# 验证
node --version
# v18.x.x
npm --version
# 9.x.x
```

### 安装 frida-node

```bash
npm install frida

# 验证安装
node -e "const frida = require('frida'); console.log('frida-node loaded');"
```

## 验证完整开发环境

创建以下测试脚本来验证环境是否可用：

```python
# test_frida_env.py
import frida
import sys

def on_message(message, data):
    print(f"[{message['type']}] {message}")

try:
    device = frida.get_usb_device()
    print(f"[+] 设备已连接: {device}")
    print(f"[+] Frida 版本: {frida.__version__}")
    print("[✓] 环境配置正确！")
except Exception as e:
    print(f"[✗] 连接失败: {e}")
    print("[!] 请确认：")
    print("   1. USB 已连接")
    print("   2. adb devices 可识别")
    print("   3. frida-server 已在设备上运行")
    print("   4. 端口已转发: adb forward tcp:27042 tcp:27042")
```

## 常见问题

### pip install 失败

```bash
# 升级 pip
pip3 install --upgrade pip

# 使用国内镜像
pip3 install frida frida-tools -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 版本冲突

```bash
# 查看已安装版本
pip3 list | grep frida

# 强制重装
pip3 install --force-reinstall frida==14.2.18
```
