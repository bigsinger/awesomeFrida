# 1.3 frida-server 安装与启动

## 版本匹配原则

**frida-server 的版本必须与 PC 端 frida 工具版本一致**。

```bash
# 查看 PC 端 frida 版本
frida --version
# 输出示例：14.1.3

pip show frida-tools
# 输出示例：frida-tools 9.2.0
```

> 注意：frida-server 的版本号匹配 `frida` 核心库，而非 `frida-tools`。

## 下载 frida-server

### 官方下载地址

```
https://github.com/frida/frida/releases
```

### 版本与架构选择

| 设备类型 | 架构 | 文件名后缀 |
|---------|------|-----------|
| 主流手机 | arm64 | `android-arm64.xz` |
| 32位手机 | arm | `android-arm.xz` |
| PC 模拟器 | x86 | `android-x86.xz` |
| 64位模拟器 | x86_64 | `android-x86_64.xz` |

### 已提供的版本文件

以下版本文件已包含在素材目录中：

```bash
# 引用自 Chap03/ 目录
# Chap03/frida-server-12.8.0-android-arm64.xz
# Chap03/frida-server-14.1.3-android-arm64.xz
# Chap04/frida-server-12.8.0-android-x86
```

## 安装与推送

### 1. 解压

```bash
# Windows - 使用 7-Zip 或 Python
python -c "import lzma; import shutil; \
data = lzma.open('frida-server-14.1.3-android-arm64.xz', 'rb').read(); \
open('frida-server-14.1.3-android-arm64', 'wb').write(data)"

# Linux/macOS
xz -d frida-server-14.1.3-android-arm64.xz
```

### 2. 推送到设备

```bash
# 推送到设备
adb push frida-server-14.1.3-android-arm64 /data/local/tmp/frida-server

# 赋予执行权限
adb shell chmod 755 /data/local/tmp/frida-server
```

### 完整脚本

```bash
#!/bin/bash
# frida-server 安装一站式脚本
# 用法：bash setup_frida_server.sh <版本> <架构>

VERSION=${1:-14.1.3}
ARCH=${2:-android-arm64}
FILENAME="frida-server-${VERSION}-${ARCH}.xz"
SERVER_NAME="frida-server-${VERSION}-${ARCH}"

# 下载
# wget https://github.com/frida/frida/releases/download/${VERSION}/${FILENAME}

# 解压
xz -d ${FILENAME}

# 推送
adb push ${SERVER_NAME} /data/local/tmp/frida-server
adb shell chmod 755 /data/local/tmp/frida-server

echo "frida-server ${VERSION} 已部署完成"
```

## 启动 frida-server

### 基本启动

```bash
adb shell
su
# 切换到 frida-server 目录
cd /data/local/tmp
# 启动（前台运行）
./frida-server
```

> 默认监听 `localhost:27042`

### 常见启动方式

```bash
# 1. 前台运行（调试用）
./frida-server

# 2. 后台运行（推荐）
./frida-server &

# 3. 指定监听地址
./frida-server -l 0.0.0.0:27042

# 4. 带日志输出
./frida-server -l 0.0.0.0:27042 -D
```

## 端口转发

PC 端需要通过端口转发才能与设备上的 frida-server 通信：

```bash
# 方式一：USB 转发（推荐）
adb forward tcp:27042 tcp:27042

# 验证转发
adb forward --list
# 输出示例：emulator-5554 tcp:27042 tcp:27042
```

## 验证连接

```bash
# 在 PC 端验证 frida-server 是否正常工作
frida-ps -U
# 如果能看到进程列表，说明连接成功
```

## 使用脚本一键启动

```bash
#!/bin/bash
# start_frida_server.sh - 一键启动 frida-server

adb shell << 'EOF'
su
/data/local/tmp/frida-server -l 0.0.0.0:27042 &
exit
exit
EOF

adb forward tcp:27042 tcp:27042
echo "frida-server 已启动，端口已转发"
frida-ps -U
```

## 常见问题

### Q1: 权限 denied
```bash
# 重新设置权限
adb shell chmod 755 /data/local/tmp/frida-server
```

### Q2: 版本不匹配
```bash
# 检查两端版本
# PC 端
frida --version

# 设备端 frida-server 版本
adb shell /data/local/tmp/frida-server --version
```

### Q3: 连接超时
```bash
# 检查端口转发状态
adb forward --list

# 清除所有转发并重新设置
adb forward --remove-all
adb forward tcp:27042 tcp:27042
```

## 小结

- frida-server 版本必须 **完全一致** 于 PC 端 frida
- 架构选择：arm64（真机）或 x86（模拟器）
- 三步走：**解压 → 推送 → 启动**
- 端口转发：`adb forward tcp:27042 tcp:27042`
- 验证：`frida-ps -U` 看到进程列表即成功
