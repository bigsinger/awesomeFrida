# 1.1 Frida简介与核心架构

## 什么是 Frida？

Frida（弗里达）是一款跨平台的动态插桩（Dynamic Instrumentation）框架，支持 **Windows、macOS、Linux、Android、iOS** 等多个平台。它允许你在不修改二进制文件的情况下，向正在运行的进程中注入 JavaScript 代码，从而实现：

- 方法 Hook（拦截与修改）
- 函数调用追踪
- 参数与返回值篡改
- 内存数据读写
- 主动调用目标方法

## 核心架构

Frida 采用经典的 **C/S（客户端/服务器）架构**：

```
┌─────────────────────────────────────┐
│              PC 端 (Client)          │
│  ├── Python (frida 绑定库)          │
│  ├── Node.js (frida-node)           │
│  ├── CLI 工具 (frida, frida-ps)     │
│  └── 自定义 JS 脚本                 │
├──────────────────┬──────────────────┤
│    USB / TCP/IP  │  frida-server    │
├──────────────────┴──────────────────┤
│           Android 设备 (Server)      │
│  ├── frida-server (守护进程)        │
│  ├── 注入的 JS 运行时 (V8/Duktape) │
│  └── 目标 App 进程                  │
└─────────────────────────────────────┘
```

**工作流程**：

1. **PC 端**编写 Frida 脚本（JavaScript）
2. 通过 **frida-server** 注入到目标 App 进程
3. 脚本在进程内执行，完成 Hook 操作
4. 结果通过 `send()` 或 `console.log()` 回传

## 三种注入模式

| 模式 | 命令 | 适用场景 |
|------|------|---------|
| **Attach** | `frida -U com.example.app` | App 已运行，动态介入 |
| **Spawn** | `frida -U -f com.example.app` | 需要从启动时开始 Hook |
| **Gadget** | 嵌入 App 内部 | 无 Root 环境、不可调试应用 |

## 最小可运行示例

以下是最简单的 Frida 注入脚本，展示了 `setImmediate` + `Java.perform` 的基本结构：

```javascript
// 引用自 Chap03/hello_world.js 第 1-5 行
setTimeout(function(){
    Java.perform(function(){
        console.log("hello world!");
    });
});
```

> **说明**：`setTimeout()` 确保脚本在进程完全加载后执行，`Java.perform()` 将代码切换到 Java 运行时环境。

## Frida 的三大组件

### 1. frida-server（服务端）

在 Android 设备上以 root 权限运行的守护进程，负责接收 PC 端的注入请求。

```bash
# 在设备上启动 frida-server
adb shell
su
/data/local/tmp/frida-server &  # 默认监听 localhost:27042
```

### 2. frida-tools（CLI 工具集）

PC 端安装的命令行工具，包含：

| 命令 | 用途 |
|------|------|
| `frida` | 交互式注入工具 |
| `frida-ps` | 列出运行中的进程 |
| `frida-trace` | 自动生成 Hook 追踪脚本 |
| `frida-ls-devices` | 列出连接的设备 |
| `frida-discover` | 发现内部调用 |

### 3. Python/Node.js 绑定（API 库）

开发自定义 Frida 客户端的基础：

```python
# Python 绑定示例（伪代码）
import frida
device = frida.get_usb_device()
session = device.attach("com.example.app")
script = session.create_script("""...""")
script.load()
```

## 核心 API 速览

| API | 用途 |
|-----|------|
| `Java.perform(fn)` | 切换到 Java 运行时 |
| `Java.use(className)` | 定位 Java 类 |
| `className.method.implementation` | Hook 方法实现 |
| `className.method.overload()` | 处理重载 |
| `send(data)` | 发回消息给客户端 |
| `console.log()` | 打印日志 |
| `rpc.exports` | 导出 RPC 接口 |

## 小结

- Frida 是 **C/S 架构**的动态插桩框架
- 核心注入模式：**Attach**（附加）、**Spawn**（启动）、**Gadget**（嵌入）
- 最小的脚本结构：`setImmediate(main)` + `Java.perform()`
- 三大组件：`frida-server`、`frida-tools`、Python/Node.js 绑定
