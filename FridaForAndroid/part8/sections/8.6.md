# 8.6 Hook libc导出函数

> 核心要点：libc 是 Android 系统最核心的库，Hook libc 中的函数可以监控文件操作、字符串处理、内存分配、线程创建等系统级行为。本节以 traceLibc.js 为例，掌握批量 Hook 系统库函数的方法。

## 1. libc 函数分类

libc 包含了大量的系统级函数，按功能分类如下：

| 类别 | 典型函数 | Hook 价值 |
|------|---------|-----------|
| 字符串操作 | `strcmp`, `strcpy`, `strlen`, `strstr` | 检测敏感字符串比较、关键词查找 |
| 内存操作 | `malloc`, `free`, `realloc`, `memcpy` | 追踪内存分配与释放、检测内存泄漏 |
| 文件操作 | `open`, `read`, `write`, `fopen`, `fputs` | 监控文件读写、文件路径捕获 |
| 网络操作 | `socket`, `connect`, `send`, `recv` | 网络连接监控 |
| 线程操作 | `pthread_create`, `pthread_mutex_lock` | 线程创建检测 |
| IO 操作 | `printf`, `puts`, `sprintf`, `snprintf` | 日志输出捕获 |

## 2. traceLibc.js 完整分析

```javascript
// 引用：Chap11/traceLibc.js（完整代码73行）
function traceNativeExport() {
    var modules = Process.enumerateModules();
    for(var i = 0; i < modules.length; i++) {
        var module = modules[i];

        // ① 只关注 libc.so
        if(module.name.indexOf("libc.so") < 0) {
            continue;
        }

        var exports = module.enumerateExports();
        console.log('module.addr', module.base);
        
        for(var j = 0; j < exports.length; j++) {
            // ② 只处理函数类型的导出
            if(exports[j].type == "function") {
                // ③ 过滤以 "str" 开头的函数（排除 _l, ld, pthread_ 等无关函数）
                if(exports[j].name.indexOf("str") >= 0 && 
                   exports[j].name.indexOf("_l") < 0 && 
                   exports[j].name.indexOf("ld") < 0 && 
                   exports[j].name.indexOf("pthread_") < 0) {
                    attach(exports[j].name, exports[j].address);
                }
            }
        }
    }
}

// ④ 通用 attach 函数
function attach(name, address) {
    console.log("attaching ", name);
    Interceptor.attach(address, {
        onEnter: function(args) {
           console.log("Entering => ", name);
           // ⑤ 读取字符串参数
           console.log("args[0] => ", args[0].readCString());
           console.log("args[1] => ", args[1].readCString());
        },
        onLeave: function(retval) {
            // 可以在这里处理返回值
        }
    });
}

function main(){
    console.log("Entering main");
    traceNativeExport();
}
setImmediate(main);
```

**逐层分析：**

1. **① 模块过滤**：`module.name.indexOf("libc.so") < 0` — 只关注 `libc.so`
2. **② 类型过滤**：`exports[j].type == "function"` — 只处理函数，排除变量
3. **③ 名字过滤**：筛选出字符串相关函数（如 `strcmp`, `strcpy`, `strstr`, `strlen`）
4. **④ 通用 attach**：统一的 `Interceptor.attach` 封装
5. **⑤ 参数读取**：`args[0].readCString()` 和 `args[1].readCString()` 读取字符串参数

## 3. Hook 字符串比较函数

### 3.1 strcmp 详解

```javascript
// int strcmp(const char *s1, const char *s2);
// 比较两个字符串，返回 0 表示相等

function hook_strcmp() {
    var addr = Module.findExportByName("libc.so", "strcmp");
    if (!addr) return;
    
    Interceptor.attach(addr, {
        onEnter: function(args) {
            this.s1 = args[0].readCString();
            this.s2 = args[1].readCString();
            
            // 检测是否在比较敏感字符串
            if (this.s1.indexOf("password") >= 0 || 
                this.s2.indexOf("password") >= 0 ||
                this.s1.indexOf("secret") >= 0 ||
                this.s2.indexOf("token") >= 0) {
                
                console.log("[strcmp] Sensitive compare detected!");
                console.log("  s1: " + this.s1);
                console.log("  s2: " + this.s2);
                
                // 获取调用栈追踪调用者
                console.log("  Backtrace:");
                Thread.backtrace(this.context, Backtracer.ACCURATE)
                    .map(DebugSymbol.fromAddress)
                    .forEach(function(frame) {
                        console.log("    " + frame);
                    });
            }
        },
        onLeave: function(retval) {
            var result = retval.toInt32();
            if (result !== 0 && this.s1 && this.s2) {
                // 可以修改返回值使比较通过
                // retval.replace(0);
            }
        }
    });
}
```

### 3.2 strstr 监控

```javascript
// char *strstr(const char *haystack, const char *needle);
// 在 haystack 中查找 needle 子串

function hook_strstr() {
    var addr = Module.findExportByName("libc.so", "strstr");
    if (!addr) return;
    
    Interceptor.attach(addr, {
        onEnter: function(args) {
            var haystack = args[0].readCString();
            var needle = args[1].readCString();
            
            // 检测是否在搜索特定关键词
            var sensitivePatterns = ["error", "exception", "failed", "certificate"];
            var isSensitive = sensitivePatterns.some(function(p) {
                return needle.indexOf(p) >= 0 || haystack.indexOf(p) >= 0;
            });
            
            if (isSensitive) {
                console.log("[strstr] Pattern search detected");
                console.log("  haystack: " + haystack.substring(0, 200));
                console.log("  needle: " + needle);
            }
        },
        onLeave: function(retval) {
            if (retval.isNull()) {
                // 没有找到匹配
            } else {
                // 找到了匹配，可以读取结果
                try {
                    console.log("[strstr] Found at: " + retval.readCString());
                } catch(e) {}
            }
        }
    });
}
```

## 4. Hook 文件操作函数

### 4.1 fopen 监控

```javascript
// FILE *fopen(const char *pathname, const char *mode);
// 打开文件

function hook_fopen() {
    var addr = Module.findExportByName("libc.so", "fopen");
    if (!addr) return;
    
    Interceptor.attach(addr, {
        onEnter: function(args) {
            var path = args[0].readCString();
            var mode = args[1].readCString();
            
            console.log("[fopen] " + path + " mode=" + mode);
            
            // 监控特定路径
            if (path.indexOf("/data/data/") >= 0) {
                console.log("[!] App data file opened: " + path);
            }
        },
        onLeave: function(retval) {
            if (retval.isNull()) {
                console.log("[fopen] Failed to open file");
            }
        }
    });
}
```

### 4.2 fputs / write 监控

```javascript
// int fputs(const char *s, FILE *stream);
// ssize_t write(int fd, const void *buf, size_t count);

function hook_file_write() {
    // Hook fputs
    var fputs = Module.findExportByName("libc.so", "fputs");
    if (fputs) {
        Interceptor.attach(fputs, {
            onEnter: function(args) {
                var content = args[0].readCString();
                console.log("[fputs] " + content);
            }
        });
    }
    
    // Hook write
    var write = Module.findExportByName("libc.so", "write");
    if (write) {
        Interceptor.attach(write, {
            onEnter: function(args) {
                var fd = args[0].toInt32();
                var buf = args[1];
                var count = args[2].toInt32();
                
                if (count > 0 && count < 4096) {
                    try {
                        var str = buf.readCString();
                        if (str && str.length > 0) {
                            console.log("[write] fd=" + fd + " count=" + count + 
                                       " data=" + str.substring(0, 100));
                        }
                    } catch(e) {
                        console.log("[write] fd=" + fd + " count=" + count + 
                                   " (binary data)");
                    }
                }
            }
        });
    }
}
```

## 5. 使用 enumerateSymbols 进行更全面的 Hook

与 `enumerateExports` 不同，`enumerateSymbols` 能捕获更多符号（包括 LOCAL 符号）：

```javascript
// 引用：Chap11/traceLibc.js 第43-64行（enumerateSymbols 变体）
function traceNativeSymbol() {
    var modules = Process.enumerateModules();
    for(var i = 0; i < modules.length; i++) {
        var module = modules[i];
        
        if(module.name.indexOf('libc.so') < 0) {
            continue;
        }
        
        var symbols = module.enumerateSymbols(); // 使用 symbols 而非 exports
        
        for(var j = 0; j < symbols.length; j++) {
            if(symbols[j].type == "function") {
                if(symbols[j].name.indexOf("str") >= 0) {
                    attach(symbols[j].name, symbols[j].address);
                }
            }
        }
    }
}
```

**exports vs symbols 对比：**

```javascript
// 实际对比
function compareExportSymbolCount() {
    var mod = Process.findModuleByName("libc.so");
    
    var exports = mod.enumerateExports();
    var symbols = mod.enumerateSymbols();
    
    console.log("[*] libc.so exports: " + exports.length);
    console.log("[*] libc.so symbols: " + symbols.length);
    
    // 找到在 exports 中没有但在 symbols 中有的函数
    var exportNames = new Set(exports.filter(e => e.type === 'function').map(e => e.name));
    var extraSymbols = symbols.filter(s => 
        s.type === 'function' && !exportNames.has(s.name));
    
    console.log("[*] Extra symbols (not in exports): " + extraSymbols.length);
    extraSymbols.slice(0, 20).forEach(function(s) {
        console.log("  " + s.name);
    });
}
```

## 6. 批量 Hook libc 所有函数的实用脚本

```javascript
// 批量 Hook libc 中所有与字符串、内存、文件相关的函数
function hook_libc_comprehensive() {
    var mod = Process.findModuleByName("libc.so");
    if (!mod) return;
    
    // 定义目标函数类别
    var patterns = {
        "string": ["str", "mem"],
        "file": ["open", "read", "write", "close", "fopen", "fread", "fwrite", 
                 "fclose", "fputs", "fgets", "remove", "rename"],
        "memory": ["malloc", "free", "realloc", "calloc", "mmap", "munmap"],
        "thread": ["pthread_create", "pthread_mutex", "pthread_cond"],
        "network": ["socket", "connect", "bind", "listen", "accept", "send", "recv"]
    };
    
    var exports = mod.enumerateExports();
    var hooked = 0;
    
    exports.forEach(function(exp) {
        if (exp.type !== "function") return;
        
        var shouldHook = false;
        for (var category in patterns) {
            if (patterns[category].some(function(p) { 
                return exp.name.indexOf(p) >= 0; 
            })) {
                shouldHook = true;
                break;
            }
        }
        
        if (shouldHook) {
            Interceptor.attach(exp.address, {
                onEnter: function(args) {
                    console.log("[libc] " + exp.name);
                    // 根据函数名智能打印参数
                    if (exp.name.indexOf("str") === 0 && args.length > 0) {
                        try {
                            console.log("  arg0: " + args[0].readCString());
                            if (args.length > 1) {
                                console.log("  arg1: " + args[1].readCString());
                            }
                        } catch(e) {}
                    }
                }
            });
            hooked++;
        }
    });
    
    console.log("[*] Hooked " + hooked + " libc functions");
}

hook_libc_comprehensive();
```

## 7. 使用 writeSomething 写入文件

`traceNative.js` 中提供了一个使用 libc 函数直接写文件的示例：

```javascript
// 引用：Chap11/traceNative.js 第1-23行
function writeSomething(path, contents) {
    // 获取 libc 中文件操作函数的地址
    var fopen_addr = Module.findExportByName("libc.so", "fopen");
    var fputs_addr = Module.findExportByName("libc.so", "fputs");
    var fclose_addr = Module.findExportByName("libc.so", "fclose");

    // 创建 NativeFunction 绑定
    var fopen = new NativeFunction(fopen_addr, "pointer", ["pointer", "pointer"]);
    var fputs = new NativeFunction(fputs_addr, "int", ["pointer", "pointer"]);
    var fclose = new NativeFunction(fclose_addr, "int", ["pointer"]);

    // 分配字符串内存
    var fileName = Memory.allocUtf8String(path);
    var mode = Memory.allocUtf8String("a+");    // 追加模式
    var contentHello = Memory.allocUtf8String(contents);

    // 调用 libc 函数
    var fp = fopen(fileName, mode);
    var ret = fputs(contentHello, fp);
    fclose(fp);
}
```

**关键模式：通过 `NativeFunction` 调用底层函数绕过 Frida API 限制**

```javascript
// NativeFunction 的使用方式
var fopen = new NativeFunction(
    fopen_addr,     // 函数地址
    "pointer",      // 返回值类型
    ["pointer", "pointer"]  // 参数类型列表

// 类型标识：
```

## 8. 实战：追踪密码校验函数

```javascript
// 通过 Hook libc 字符串函数来破解密码校验
function crack_password_check() {
    var capturedPasswords = new Set();
    
    // Hook strcmp — 密码比较
    var strcmp = Module.findExportByName("libc.so", "strcmp");
    Interceptor.attach(strcmp, {
        onEnter: function(args) {
            var s1 = args[0].readCString();
            var s2 = args[1].readCString();
            
            // 看起来像密码的参数
            if (s1.length > 4 && s1.length < 64 && 
                s2.length > 4 && s2.length < 64) {
                
                // 检测是否是比较密码
                var caller = this.context.lr;
                var mod = Process.findModuleByAddress(caller);
                if (mod && mod.path.indexOf("/data/app/") >= 0) {
                    console.log("[!] strcmp in app code");
                    console.log("  s1: " + s1);
                    console.log("  s2: " + s2);
                    
                    // 短字符串可能是密码
                    if (s1.length < 32) capturedPasswords.add(s1);
                    if (s2.length < 32) capturedPasswords.add(s2);
                }
            }
        }
    });
    
    // Hook strlen 也可以帮助定位密码
    var strlen = Module.findExportByName("libc.so", "strlen");
    Interceptor.attach(strlen, {
        onEnter: function(args) {
            // 不需要做什么，除非想统计字符串长度分布
        }
    });
}

crack_password_check();
```

## 总结

- **traceLibc.js** 展示了通过 `enumerateExports` 批量 Hook 系统库函数的经典模式
- **enumerateExports vs enumerateSymbols**：前者只捕获 GLOBAL 导出，后者更全面
- **字符串函数**（strcmp/strstr/strlen）是追踪数据流的关键 Hook 点
- **文件操作函数**（fopen/fputs/write）可以监控所有文件读写行为
- **NativeFunction** 允许我们在 Frida 脚本中直接调用 libc 函数
- **模式过滤**：通过函数名匹配精确筛选目标函数，避免 Hook 过多影响性能
- 批量 Hook libc 函数时需要**注意性能影响**，避免 Hook 过于频繁的函数
