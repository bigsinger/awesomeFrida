# 5.1 OkHttp Hook：拦截器注入

> OkHttp 是 Android 上最流行的 HTTP 客户端。拦截器（Interceptor）是 OkHttp 的核心设计模式之一。通过在 Frida 中**动态注册**自定义拦截器，可以拦截 App 的所有 OkHttp 请求。

## 1. 方案概览

针对 OkHttp 的 Hook 有两种主流方案：

| 方案 | 原理 | 优点 | 缺点 |
|:---:|:---|:---|:---|
| **拦截器注入** | 通过 `Java.registerClass` 注册自定义 Interceptor，注入到 OkHttpClient 的拦截器链 | 可查看完整 Request/Response | 需要先构建 Dex 或动态注册类 |
| **newCall Hook** | Hook `OkHttpClient.newCall` 方法 | 实现简单，无需注册类 | 只能看到 Request，Response 需额外 Hook |

本节讲解第 1 种方案。

> **引用**：
> - `AndroidFridaBeginnersBook-main/Chap08/hookInteceptor.js`（25行）
> - `awesomeFrida/hook_okhttp3.js`（121行）

## 2. 方案一：动态注册拦截器类（Dex注入）

```javascript
// 引用：AndroidFridaBeginnersBook-main/Chap08/hookInteceptor.js 完整代码
function hook_okhttp3() {
    Java.perform(function () {
        // 加载预编译的 Dex 文件（包含 LoggingInterceptor 类）
        Java.openClassFile("/data/local/tmp/okhttp3logging.dex").load();

        var MyInterceptor = Java.use("com.r0ysue.okhttp3demo.LoggingInterceptor");
        var MyInterceptorObj = MyInterceptor.$new();
        var Builder = Java.use("okhttp3.OkHttpClient$Builder");

        console.log(Builder);
        Builder.build.implementation = function () {
            this.networkInterceptors().add(MyInterceptorObj);
            return this.build();
        };
        console.log("hook_okhttp3...");
    });
}
function main() {
    hook_okhttp3();
}
setImmediate(main)
```

### 执行流程

```
1. Java.openClassFile("/data/local/tmp/okhttp3logging.dex").load()
   → 将预编译的 LoggingInterceptor Dex 加载到 App 进程

2. Java.use("com.r0ysue.okhttp3demo.LoggingInterceptor")
   → 获取 LoggingInterceptor 类

3. MyInterceptor.$new()
   → 创建拦截器实例

4. Builder.build.implementation = function() { ... }
   → Hook Builder.build()，将自定义拦截器注入 networkInterceptors

5. this.networkInterceptors().add(MyInterceptorObj)
   → 将拦截器添加到网络拦截器链
```

### 优点和局限

**优点**：
- 拦截器基于 OkHttp 官方 API，兼容性好
- 可以完整看到 Request/Response body
- 支持修改请求内容

**局限**：
- 需要预编译 Dex 文件（编写 Java 代码 + 编译）
- 运行时需要推送 Dex 到 `/data/local/tmp/`

## 3. 方案二：纯 JS 注册拦截器类

无需预编译 Dex，直接在 Frida 中通过 `Java.registerClass` 注册：

```javascript
// 引用：awesomeFrida/hook_okhttp3.js 第 1-121 行
function hook_okhttp3() {
    Java.perform(function () {
        var ByteString = Java.use("com.android.okhttp.okio.ByteString");
        var Buffer = Java.use("com.android.okhttp.okio.Buffer");
        var Interceptor = Java.use("okhttp3.Interceptor");
        var ArrayList = Java.use("java.util.ArrayList");
        var OkHttpClient = Java.use("okhttp3.OkHttpClient");

        // 注册自定义拦截器类
        var MyInterceptor = Java.registerClass({
            name: "okhttp3.MyInterceptor",
            implements: [Interceptor],
            methods: {
                intercept: function (chain) {
                    var request = chain.request();
                    try {
                        console.log("Request:", request, "\nheaders:", request.headers());
                        var requestBody = request.body();
                        var contentLength = requestBody ? requestBody.contentLength() : 0;
                        if (contentLength > 0) {
                            var BufferObj = Buffer.$new();
                            requestBody.writeTo(BufferObj);
                            try {
                                console.log("request body:\n", BufferObj.readString());
                            } catch (error) {
                                console.log("request body hex:\n",
                                    ByteString.of(BufferObj.readByteArray()).hex());
                            }
                        }
                    } catch (error) {
                        console.log("error:", error);
                    }
                    var response = chain.proceed(request);
                    // ... 处理 Response（略）
                    return response;
                }
            }
        });

        var MyInterceptorObj = MyInterceptor.$new();
        var Builder = Java.use("okhttp3.OkHttpClient$Builder");

        Builder.build.implementation = function () {
            this.interceptors().clear();
            this.interceptors().add(MyInterceptorObj);
            return this.build();
        };

        Builder.addInterceptor.implementation = function (interceptor) {
            this.interceptors().clear();
            this.interceptors().add(MyInterceptorObj);
            return this;
        };

        console.log("hook_okhttp3...");
    });
}
setImmediate(hook_okhttp3());
```

### Java.registerClass 详解

| 参数 | 说明 | 示例 |
|:---|:---|:---|
| `name` | 注册的类名 | `"okhttp3.MyInterceptor"` |
| `implements` | 实现的接口列表 | `[Interceptor]` |
| `methods` | 实现的方法 | `{ intercept: function(chain) { ... } }` |
| `superClass` | 可选的父类 | `{ superClass: Java.use('...') }` |

### interceptor 添加时机

`hook_okhttp3.js`（第 100-112 行）Hook 了两个关键的添加时机：

1. **`Builder.build()`** — 在构建 OkHttpClient 时注入
2. **`Builder.addInterceptor()`** — 在 App 调用 `addInterceptor` 时替换

```javascript
// 时机1: build 时注入
Builder.build.implementation = function () {
    this.interceptors().clear();
    this.interceptors().add(MyInterceptorObj);
    return this.build();
};

// 时机2: 替换 App 自己的拦截器
Builder.addInterceptor.implementation = function (interceptor) {
    this.interceptors().clear();
    this.interceptors().add(MyInterceptorObj);
    return this;
};
```

## 4. 查看 Request Body

`hook_okhttp3.js` 第 30-44 行展示了如何读取请求体：

```javascript
var requestBody = request.body();
if (requestBody && requestBody.contentLength() > 0) {
    var BufferObj = Buffer.$new();
    requestBody.writeTo(BufferObj);
    try {
        console.log("request body:\n", BufferObj.readString());
    } catch (error) {
        // 非 UTF-8 内容，以 Hex 输出
        console.log("request body hex:\n",
            ByteString.of(BufferObj.readByteArray()).hex());
    }
}
```

## 5. 查看 Response Body

var response = chain.proceed(request);

if (ContentType.indexOf("video") == -1) {  // 过滤视频流
    if (ContentType.indexOf("application") == 0 && ContentType.indexOf("application/zip") != 0) {

## 6. 数据篡改

拦截器不仅可以查看数据，还可以**修改请求和响应**：

```javascript
methods: {
    intercept: function (chain) {
        var request = chain.request();

        // 修改 Request Header
        var newRequest = request.newBuilder()
            .header("User-Agent", "Frida-Injected")
            .header("X-Frida", "true")
            .build();

        var response = chain.proceed(newRequest);

        // 修改 Response Body
        var newResponse = response.newBuilder()
            .header("X-Frida-Response", "injected")
            .body(okhttp3.ResponseBody.create(
                okhttp3.MediaType.parse("application/json"),
                '{"injected": true}'
            ))
            .build();

        return newResponse;
    }
}
```

## 7. 运行命令

```bash
# 方案一（需要预编译 Dex）
adb push okhttp3logging.dex /data/local/tmp/
frida -U -f com.roysue.okhttp3demo -l hookInteceptor.js --no-pause

# 方案二（纯 JS）
frida -U -f com.roysue.targetapp -l hook_okhttp3.js --no-pause
```

> **引用**：`Chap08/hookInteceptor.js` 使用 Dex 注入方案；`awesomeFrida/hook_okhttp3.js` 使用纯 JS `Java.registerClass` 方案。两种方案各有优劣，推荐在生产环境中使用方案二。
