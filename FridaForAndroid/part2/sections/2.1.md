# 2.1 Hello World：注入脚本

## 第一个 Frida 脚本

创建 `hello_world.js`：

```javascript
// 引用自 Chap03/hello_world.js 第 1-5 行（完整代码）
setTimeout(function(){
    Java.perform(function(){
        console.log("hello world!");
    });
});
```

> **来源**：`Chap03/hello_world.js`（完整文件，共 4 行有效代码）

### 代码结构拆解

| 部分 | 作用 |
|------|------|
| `setTimeout(function(){...})` | 延迟执行，确保进程初始化完成 |
| `Java.perform(function(){...})` | 切换到 Java 运行时环境 |
| `console.log("hello world!")` | 在目标进程内打印日志 |

> 💡 `setTimeout` 将函数推迟到当前事件循环完成后执行，确保 `Java.perform` 调用时 Frida 的运行时已就绪。另一种等效写法是 `setImmediate(main)`。

## 运行脚本

### 方法一：Attach 模式（App 已运行）

```bash
# 1. 先在设备上启动目标 App
# 2. 在 PC 端执行
frida -U com.roysue.demo02 -l hello_world.js
```

**输出：**
```
     ____
    / _  |   Frida 14.1.3 - A world-class dynamic instrumentation toolkit
   | (_| |
    > _  |   Commands:
   /_/ |_|       help      -> Displays the help system
   . . . .       more      -> Displays more information

[Android Emulator] - com.roysue.demo02 (11792):
Script loaded successfully
hello world!
```

### 方法二：Spawn 模式（自动启动 App）

```bash
# 自动启动 App 并注入脚本
frida -U -f com.roysue.demo02 -l hello_world.js

# --no-pause 选项让 App 不暂停执行
frida -U -f com.roysue.demo02 -l hello_world.js --no-pause
```

## 使用 setImmediate 的等价写法

```javascript
// 等效写法：使用 setImmediate 替代 setTimeout
function main() {
    Java.perform(function() {
        console.log("hello world!");
    });
}

setImmediate(main);
```

> 这种写法将 main 函数独立定义，结构更清晰，是后续所有 Frida 脚本的标准模式。

## 完整运行流程

```
PC 端                           Android 设备
─────                           ────────────
frida -U xxx -l hello.js  ──→  frida-server (接收请求)
         │                           │
         │                    ──→  目标 App 进程
         │                           │
         │                    ←──  注入 JS 运行时
         │                           │
         │                    ──→  执行 console.log()
         │                           │
         │←── "hello world!" ──→  打印到控制台
```

## 进阶：带消息回调的 Hello World

```javascript
function main() {
    Java.perform(function() {
        var MainActivity = Java.use('com.roysue.demo02.MainActivity');
        console.log("Java.Use.Successfully!");
        
        // 发送消息回 PC 端
        send("hello from Frida!");
    });
}

setImmediate(main);
```

## 验证脚本是否正常运行

1. 如果控制台打印出 `Script loaded successfully` 和 `hello world!`
2. 说明注入成功，frida-server 工作正常
3. 如果没有输出，请检查：
   - frida-server 是否在运行
   - 端口转发是否设置
   - 包名是否正确
   - App 是否已启动

## 小结

- 最小 Frida 脚本：`setTimeout/Immediate` + `Java.perform` + `console.log`
- 两种运行方式：**Attach**（附加）和 **Spawn**（启动）
- `setImmediate(main)` 是标准实践，将逻辑封装在 main 函数中
- 第一个成功运行的脚本验证了整套工具链的正确性
