# 2.4 日志输出：console.log 与 send

## 概述

Frida 提供两种主要的日志输出方式：

| 方式 | 输出位置 | 是否传递到客户端 | 适用场景 |
|------|---------|----------------|---------|
| `console.log()` | 目标进程标准输出 | ❌ 不传递 | 简单调试、终端使用 |
| `send()` | 目标进程 → 客户端回调 | ✅ 传递 | Python 客户端、需要处理数据 |

## console.log：终端输出

### 基本用法

```javascript
// 引用自 Chap03/1.js 第 2-4 行（console.log 用法）
function main(){
    console.log("Script loaded successfully ")
    Java.perform(function(){
        console.log("Inside java perform function")
        var MainAcitivity = Java.use('com.roysue.demo02.MainActivity')
        console.log("Java.Use.Successfully!") //定位类成功！
        // ...
    })
}
setImmediate(main)
```

> **来源**：`Chap03/1.js` 第 2-4 行，展示了 `console.log` 的典型用法。

### 输出位置

```bash
# 使用 frida CLI 时，console.log 直接输出到终端
frida -U com.roysue.demo02 -l script.js

# 输出：
# Script loaded successfully 
# Inside java perform function
# Java.Use.Successfully!
```

**`console.log` 的输出特点：**
- 直接打印在 **frida CLI 的终端**上
- **不传递**到 Python 客户端的 `on_message` 回调
- 支持格式化输出：`console.log("x =>", x, ", y =>", y)`
- 可打印对象：`console.log(JSON.stringify(obj))`

## send：客户端消息传递

### 基本用法

`send()` 将消息从目标进程发送到 PC 客户端的回调函数：

```javascript
function main() {
    Java.perform(function() {
        // 发送简单字符串
        send("hello from target process!");
        
        // 发送对象
        send({
            type: "hook_result",
            class: "com.roysue.demo02.MainActivity",
            method: "fun",
            args: [1, 2],
            result: "modified"
        });
        
        // 发送带类型标记的消息
        send({event: "hook_attached", detail: "MainActivity.fun"});
    });
}
setImmediate(main);
```

### Python 端接收

```python
# 引用自 Chap04/loader.py 第 3-7 行（on_message 回调）
import frida, sys

def on_message(message, data):
    if message['type'] == 'send':
        print("[*] {0}".format(message['payload']))
    else:
        print(message)
```

> **来源**：`Chap04/loader.py` 第 3-7 行，展示了标准的 `on_message` 回调处理。

### send 的数据类型

```python
# Python 端可以接收各种类型
def on_message(message, data):
    if message['type'] == 'send':
        payload = message['payload']
        
        if isinstance(payload, str):
            print(f"[STRING] {payload}")
        elif isinstance(payload, dict):
            print(f"[DICT] event={payload.get('event')}")
            print(f"[DICT] detail={payload.get('detail')}")
        elif isinstance(payload, list):
            print(f"[LIST] length={len(payload)}")
        else:
            print(f"[OTHER] {payload}")
    elif message['type'] == 'error':
        print(f"[ERROR] {message}")
```

## console.log vs send：对比

```javascript
function main() {
    console.log("This goes to terminal only");
    
    // console.log 不支持结构化数据
    console.log({a: 1, b: 2});  // 输出 [object Object]
    
    send("This goes to Python on_message");
    
    // send 支持结构化数据
    send({a: 1, b: 2});  // Python 收到 dict
}
```

| 特性 | console.log | send |
|------|------------|------|
| 输出终端 | frida CLI | ❌ 不显示 |
| Python 接收 | ❌ | ✅ on_message |
| 结构化数据 | ❌ 显示为 `[object Object]` | ✅ 保持 JSON |
| 性能消耗 | 低 | 略高（序列化开销） |
| 使用场景 | 快速调试 | 生产脚本 |

## 实战：结构化日志输出

```javascript
function main() {
    Java.perform(function() {
        var MainActivity = Java.use('com.roysue.demo02.MainActivity');
        
        MainActivity.fun.implementation = function(x, y) {
            // 使用 console.log 实时查看
            console.log("fun called with x:", x, "y:", y);
            
            // 使用 send 发送结构化数据给客户端
            send({
                event: "method_called",
                class_name: "MainActivity",
                method_name: "fun",
                args: {x: x, y: y},
                thread: Process.getCurrentThreadId()
            });
            
            var result = this.fun(x, y);
            
            send({
                event: "method_returned",
                result: result
            });
            
            return result;
        };
    });
}
setImmediate(main);
```

## 进阶：send + 二进制数据

`send()` 的第二个参数可以传递二进制数据：

```javascript
// JS 端
var buffer = Memory.readByteArray(ptr("0x1234"), 16);
send("raw_data", buffer);

// Python 端
def on_message(message, data):
    if message['type'] == 'send':
        print(f"Payload: {message['payload']}")
        if data:
            print(f"Binary data length: {len(data)} bytes")
            print(f"First 4 bytes: {data[:4].hex()}")
```

## 日志级别约定

推荐在团队协作中使用标准日志级别：

```javascript
function log_debug(msg) { send({level: "DEBUG", msg: msg}); }
function log_info(msg)  { send({level: "INFO",  msg: msg}); }
function log_warn(msg)  { send({level: "WARN",  msg: msg}); }
function log_error(msg) { send({level: "ERROR", msg: msg}); }

// 使用
log_info("Script loaded");
log_debug("Hook attached to MainActivity.fun");
log_warn("Unusual parameter detected");
```

## 小结

| 方式 | 用途 |
|------|------|
| `console.log()` | 终端快速调试，简单直接 |
| `send()` | 将结构化数据传递给 Python 客户端 |
| `send(msg, data)` | 传递二进制数据 |

- **`console.log`**：直观，适合 CLI 调试
- **`send`**：结构化、可编程，适合 Python 自动化
- 两者可以**同时使用**，互补不冲突
- 推荐使用结构化 `send` + Python `on_message` 处理生产脚本
