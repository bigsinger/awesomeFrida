# 2.3 Java.perform 详解

## 为什么需要 Java.perform？

Frida 的 JavaScript 引擎（V8/Duktape）运行在 **目标进程的用户态空间**，但它和 Java 虚拟机（ART/Dalvik）是在 **两个不同的运行时** 中运行的。要调用 Java 层的 API（如 `Java.use`、`Java.choose`），必须通过 `Java.perform()` 切换到 Java 运行时上下文。

> **一句话**：`Java.perform` 是 JavaScript 世界进入 Java 世界的桥梁。

## 基本结构

```javascript
// 引用自 Chap03/1.js 第 1-13 行（main 函数完整结构）
function main(){
    console.log("Script loaded successfully ")
    Java.perform(function(){
        console.log("Inside java perform function")
        var MainAcitivity = Java.use('com.roysue.demo02.MainActivity')
        console.log("Java.Use.Successfully!") //定位类成功！
        MainAcitivity.fun.implementation = function(x,y){
            console.log("x => ",x,", y => ",y)
            var ret_value = this.fun(x, y);
            return ret_value
        }
    })
}
function testJavaPerform(){
    console.log("Script loaded successfully ")
        var MainAcitivity = Java.use('com.roysue.demo02.MainActivity')
        console.log("Java.Use.Successfully!") //定位类成功！
        MainAcitivity.fun.implementation = function(x,y){
            console.log("x => ",x,", y => ",y)
            var ret_value = this.fun(x, y);
            return ret_value
        }
}
setImmediate(main)
```

> **来源**：`Chap03/1.js` 第 1-13 行（`main` 函数）和第 14-26 行（`testJavaPerform` 函数，无 `Java.perform` 的错误示例）。

### 关键观察

第 14-26 行的 `testJavaPerform` 函数**没有使用 `Java.perform`**——如果你直接调用它会报错：

```
Error: use(): must be called from Java.perform() callback
```

## Java.perform 的内部机制

```
┌─────────────────────────────────────┐
│        JavaScript 运行时              │
│  （V8 / Duktape）                    │
│                                      │
│  Java.perform(callback)  ────────────│──→ ART 运行时线程切换
│                                      │    │
│  callback() 中的代码          ←──────│←── 在 Java 线程上执行
│    Java.use()                        │
│    implementation = ...             │
│    console.log()                     │
└─────────────────────────────────────┘
```

### 执行流程

1. **调用 `Java.perform(callback)`**
2. Frida 内部获取 Java 运行时（ART）的 **主线程**（UI 线程）
3. 将 `callback` 函数发送到该线程执行
4. 在 callback 内部，所有 Java API 可用
5. callback 执行完毕后，控制权返回 JS 引擎

## 嵌套与多个 Java.perform

```javascript
function main() {
    Java.perform(function() {
        console.log("First Java.perform");
        
        Java.perform(function() {
            console.log("Nested Java.perform - also valid");
            
            // 在嵌套内部也可以继续嵌套
            Java.perform(function() {
                console.log("Three levels deep");
            });
        });
        
        console.log("Back to first perform");
    });
}
setImmediate(main);
```

> 💡 `Java.perform` 支持嵌套调用，多个 `Java.perform` 按 **执行顺序排队** 在同一个 Java 线程上执行。

## 在 Java.perform 外能做什么？

虽然 `Java.perform` 之外不能调用 Java API，但可以做：

```javascript
// 在 Java.perform 外面可以做这些
console.log("JS 层面的代码");
var counter = 0;

// 定义辅助函数
function helper() {
    return "from helper";
}

// 普通 JS 变量操作
var config = {
    target_class: "com.roysue.demo02.MainActivity",
    debug: true
};

// 在 Java.perform 内部使用这些变量
Java.perform(function() {
    console.log(helper());  // 可以！
    console.log(config.target_class);  // 可以！
    
    Java.use(config.target_class);  // 核心操作必须在内部
});
```

## 常见错误

### 错误 1：在 Java.perform 外使用 Java API

```javascript
// ❌ 错误！会抛出异常
var MainActivity = Java.use('com.roysue.demo02.MainActivity');

// ✅ 正确
Java.perform(function() {
    var MainActivity = Java.use('com.roysue.demo02.MainActivity');
});
```

### 错误 2：长时间阻塞

```javascript
// ❌ 不要在 Java.perform 内做耗时操作
Java.perform(function() {
    while(true) { }  // 会卡死主线程
});

// ✅ 耗时操作移到外部
function heavyTask() {
    // JS 层面的计算
}
Java.perform(function() {
    // 只放必要的 Java 操作
});
```

## Java.perform 的同步特性

`Java.perform` 是 **同步阻塞** 的——在 callback 返回之前，后续 JS 代码不会执行：

```javascript
function main() {
    console.log("1 - before Java.perform");
    
    Java.perform(function() {
        console.log("2 - inside Java.perform");
        // 模拟耗时
        for(var i = 0; i < 1000000; i++) { }
    });
    
    console.log("3 - after Java.perform"); // 等 2 完成后才执行
}
setImmediate(main);
// 输出顺序：1 → 2 → 3
```

## 小结

- `Java.perform(callback)` 是 **JavaScript → Java 运行时** 的桥梁
- 所有 Java API（`Java.use`、`Java.choose` 等）**必须**在 callback 内部调用
- 支持 **嵌套**，多个 `Java.perform` 排队执行
- 在 callback 外可以做 JS 层面的逻辑操作
- **不要**在 callback 内做耗时操作，会阻塞 UI 线程
- 标准结构：`function main()` → `Java.perform()` → `Java.use()` → `implementation`
